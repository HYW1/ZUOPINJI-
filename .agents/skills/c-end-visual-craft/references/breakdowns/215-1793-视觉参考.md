## section/01 主视觉锚点（未变，摘要）

1. **主视觉锚点：** 右侧/居中可触摸 3D 物（玻璃卡、方块、水晶图标、金属环、立体数字）
2. **背景：** 浅底 + 轻雾；主体与背景靠软影分离
3. **可迁移：** 一物一材质；左信息右主物；短软接触影
4. **不要学：** 霓虹涡旋铺满；多层玻璃叠罗汉；虹彩丝带无节制

---

## section/02 背景与氛围（未变，摘要）

1. **主角是氛围：** 柔光色雾、棱镜细光、丝带光带
2. **三层背景：** 实底 → 大半径色团 → 少量细节光/颗粒
3. **可迁移：** 页头上 1/3 淡蓝雾；内容区回稳白
4. **不要学：** 暗黑赛博紫青；彩虹棱镜铺满首屏

---

## section/04 卡片与层次（未变，摘要）

1. **浅色软阴影 / 暗色边缘高光**，勿双堆
2. **卡片是交互容器**，不是段落外框
3. **一张卡一个锚点**（数/图标/小插画）
4. **不要学：** 霓虹描边卡片墙；深色玻璃列表当支付宝默认皮

## section/05 插画与图标（重写 · 扩充后）

### 1. 主视觉锚点是什么
- **Hero 级：** 有厚度的玻璃/抛光盾、银行建筑、家庭/老人 3D 角色、保护伞等单隐喻
- **系统级：** 统一光照的软 3D 功能图标网格（橙系财务隐喻 / 多色入口）
- 材质：霜化玻璃折射 + 磨砂树脂（clay）混用，但 **单物件主材质仍要说得清**

### 2. 背景如何做氛围
- 海报：白/浅灰底 + 大半径软影；或极淡品牌色雾
- 角色场景：浅平台/轻投影，不靠厚色块墙

### 3. 层次怎么分
| 层 | 内容 | 手法 |
|----|------|------|
| 前景 | 主 3D、漂浮小物件（币/心/勾） | 不同景深与尺寸 |
| 内容 | 标题/利益点（若在海报内） | 字重对比，勿烧进主物 |
| 背景 | 浅底或轻雾 | 干净，留给透明主物叠合 |

### 4. 材质与光影技巧（1–3 条）
1. **盾要有厚度与折射**：玻璃边高光 + 内芯实色；导出必须 **透明底可抠**，禁止烘焙方板/云雾底板  
2. **内发光克制**：光像来自物体内或顶侧方向光，不是满屏 glow  
3. **功能图标一套光源**：同角度、同阴影软度；Hero 才升级材质档

### 5. 排版与留白节奏（本板附带海报）
- 主物居中或右锚，周围留呼吸；小漂浮物打破呆板，但数量克制  
- 角色表情服务信任感，不抢主 CTA

### 6. 可迁移到我的稿
- 结果/保障态：透明玻璃盾或单隐喻 3D（抠图后叠氛围）  
- 入口宫格：统一软 3D，不与 Hero 同档材质混用  
- 营销模块才用家庭角色；工具表单页不用群像

### 7. 不要学
- 塑料贴纸人、无品牌的漂浮几何墙  
- 把海报整页糊进工具页当背景  
- 盾牌带白底方卡/棋盘格未处理就上屏

## section/08 排版与留白（纠正 · 整板替换后）

> 本板现为 **真实手机屏的字号/留白/节奏**，不是插画海报。

### 1. 主视觉锚点是什么
- 左例：页头小 3D（纸飞机）作轻锚点，**不压过标题层级**  
- 中例：单屏单焦点（中心设备/大圆钮）  
- 右例：顶部色带标题 + 大数字指标

### 2. 背景如何做氛围
- 高键浅蓝/薄荷绿 → 白内容溶入  
- 可加 **极淡地形线/微纹理** 增加触感（非装饰贴图墙）  
- 深色单屏：饱和单色底 + 半透明图标层（慎用于支付宝默认工具页）

### 3. 层次怎么分
| 层 | 内容 | 手法 |
|----|------|------|
| 前景 | 关键数字、主图表、主按钮 | 字号/字重跳级 |
| 内容 | 白卡片模块、说明 | 大内边距、圆角一致 |
| 背景 | 浅灰/浅色雾 | 与白卡明度差很小即可

### 4. 材质与光影技巧（1–3 条）
1. **疏朗 > 堆满**：模块间大呼吸，组内紧  
2. **双层软阴影** 抬白卡，避免默认单层脏影  
3. **指标先行**：金额/分数/百分比极大，标签灰色退后

### 5. 排版与留白节奏
- 标题区：主标题大、副文小且疏  
- 图表与卡片周围留白充足，不贴边  
- 一屏少焦点；信息用网格对齐而非再套厚卡

### 6. 可迁移到我的稿
- 工具/报告页：顶区淡雾 + 大标题 + 下方白岛模块（对齐 08 左/右例）  
- 数字/环形进度做舞台，装饰锚点缩小  
- 内边距按 8 栅格加码，宁可少模块

### 7. 不要学
- 中例暗蓝霓虹大圆钮当支付宝默认皮  
- 为「高级」加满拟态凹凸  
- 把本板当成插画素材库（插画看 05）

## section/09 金融保险优秀案例（加强 · 扩充后）

### 1. 主视觉锚点是什么
- 3D 盾/心/金币（透明可叠）  
- 生活/医护摄影 + 软遮罩溶入头图  
- 大数字 / 评分仪表盘 /「100%」利益点  
- 偶见克制玻璃浮层（授权弹层、底栏）

### 2. 背景如何做氛围
- 顶区品牌色极淡纵向溶白；内容区浅灰托白卡  
- 头图摄影区与下方列表用渐变遮罩过渡  
- 微颗粒/细网纹可选，强度极低

### 3. 层次怎么分
| 层 | 内容 | 手法 |
|----|------|------|
| 前景 | 3D 可压住卡片边缘、主 CTA | 轻微越界增加景深 |
| 内容 | 白卡模块、列表、图表 | 长距低透明阴影 |
| 背景 | 顶雾/摄影/浅灰 | 氛围不超过上半屏

### 4. 材质与光影技巧（1–3 条）
1. **长距、低透明软阴影** 让卡浮起，代替重描边  
2. **3D 与摄影二选一做主锚**，另一退为辅  
3. **玻璃只用在局部浮层**，不做整页玻璃堆

### 5. 排版与留白节奏
- 关键数据超大；说明灰且小  
- 模块分组清晰，组间空白像「呼吸」不是缝线塞满  
- 健康金/财富色（金橙）可用，但支付宝落地时映射克制 + `#1677FF` 行动色

### 6. 可迁移到我的稿（支付宝 C 端默认优先看本板）
- 结果页：顶雾 +（透明）材质主视觉 + 数字舞台 + 下方规范列表  
- 保障/财富：摄影或 3D 头图溶入，白卡承载信息  
- 主物可轻微压住卡片上沿（景深），但须已抠透明底

### 7. 不要学
- 照搬绿/金主题大面积墙  
- 暗色高光玻璃大卡当默认工具态  
- 为炫技把列表改成霓虹仪表盘（对照 section/10）
