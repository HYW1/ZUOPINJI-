# 案例 · 结果页双方案（卡片 / 运营）

**目标文件：** https://www.figma.com/design/DLepVQbX1Ll21Y2fh1kmyU/就医报销  
**方案A · 卡片质感：** `149:689`  
**方案B · 运营质感：** `149:787`  
**对照旧稿：** 卡片原 `129:668` · 运营旧 `135:689`  
**画布：** 750×1624 · 行动色 `#1677FF`

## 用户反馈（本轮硬约束）

- 两版都要继续优化，旧稿「没有质感」
- 运营版图标丑 → 重生图 + 强制透明抠图
- **卡不要加阴影**（层次改用页底对比 + 细描边 + 内嵌浅底）

## 方案A · 卡片质感（工具页公式）

| 项 | 做法 |
|----|------|
| 顶雾 | 轻蓝→页底渐隐，不做摄影糊底 |
| 状态岛 | 白卡 + `#D9E1EC` 内描边，无投影 |
| 统计 | 浅灰内嵌舞台，待处理 `0` 降饱和 |
| 锚点 | 右上小尺寸透明玻璃盾（克制） |
| 材料岛 | 白卡细描边；帮助条浅底 |
| CTA | 实色 `#1677FF`，无 glow |

链接：https://www.figma.com/design/DLepVQbX1Ll21Y2fh1kmyU/就医报销?node-id=149-689

## 方案B · 运营质感（氛围 + 主视觉）

| 项 | 做法 |
|----|------|
| 氛围 | 顶区软雾洗色（去掉射线摄影底） |
| 主视觉 | 大尺寸透明玻璃盾（FIT，无底板） |
| 文案 | 「状态文案底」白岛承载，禁止裸字叠雾 |
| 数字舞台 | 独立白岛 + 竖分割，无投影 |
| 材料点缀 | 透明文件夹图标（抠图） |
| 层次 | 页底 `#EBF0F6` 托白岛；**全树无 DROP_SHADOW** |

链接：https://www.figma.com/design/DLepVQbX1Ll21Y2fh1kmyU/就医报销?node-id=149-787

## 素材流程

1. 绿幕生图（盾 / 文件夹）
2. rembg 抠成 RGBA
3. `IMAGE` + `FIT` 嵌入，禁止带圆盘光底板
4. 卡片只保留描边与底色差，不加阴影
