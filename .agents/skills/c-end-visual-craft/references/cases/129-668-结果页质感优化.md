## 改前问题（诊断）

- 顶区偏「浅蓝玻璃墙」：状态卡 BACKGROUND_BLUR + 淡蓝渐变，像特效叠层而非产品质感
- 主视觉弱：仅小勾选图标 + 蓝色标题，缺少可命名材质锚点
- 层次靠厚卡片嵌套（蓝底卡套白统计卡套内容卡）
- 上传空槽扁平灰块；主按钮虽有蓝，但整体仍像组件拼装

## 模块改动清单

1. **背景**：削弱大面积蓝墙 → 中性底 + 顶区轻雾  
2. **状态岛**：实色白卡 + 软阴影；标题改墨色；徽章替换扁图标  
3. **统计**：浅底舞台 + 竖分割；数字层级强化  
4. **材料区**：白岛轻阴影；帮助条降饱和；空槽虚线描边；缩略图软阴影  
5. **主按钮**：实色 `#1677FF` + 克制投影  
6. **生图**：仅 1 张成功徽章（单模块），校验后嵌入  

## 验收（对照 Skill）

## v2 加强点（相对 v1）

- 顶区换成氛围摄影底，而非纯色雾矩形
- 右侧大尺寸玻璃盾主视觉 + 装饰环 + 局部光（左文右锚点）
- 统计改为半透明浮层数字舞台，叠在氛围区与内容区之间
- 材料岛双层阴影 + 顶缘高光；帮助条左边品牌色条
- 材料标题旁文件夹 3D 点缀（单模块生图）
- 主按钮投影加强，仍保持实色 `#1677FF`
