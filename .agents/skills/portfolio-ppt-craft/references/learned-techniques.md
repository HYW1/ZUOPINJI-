### T-001 · 一页一锚点
- 来源参考：种子（通用作品集）
- 作用层：主视觉 / 排版
- 适用场景：封面、案例开场、结果页、任意演讲页
- 做法：每页只保留一个第一眼落点（封面人 / 项目主图 / 关键界面 / 过程物，二选一为主）；其余退为衬托；标题与标注不与锚点抢面积
- 禁止项：双主锚（大插画 + 大截图同时抢戏）；用装饰物冒充锚点

### T-002 · 疏朗封面舞台
- 来源参考：种子（通用作品集）
- 作用层：排版 / 背景
- 适用场景：封面、章节页、过渡页
- 做法：极克制中性底 + 姓名/角色一句 + 一个真实作品锚点或留白舞台；大留白制造投屏气场
- 禁止项：紫渐变科技皮；图标行 + 胶囊标签丛 + 假统计条塞满封面；满页英文废话大词

### T-003 · 真截图压过装饰
- 来源参考：种子（通用作品集）
- 作用层：摄影或截图 / 层次
- 适用场景：案例开场、过程页、结果页
- 做法：界面 / 动效帧 / 过程稿必须真实可读；装饰与材质只做衬托；模糊看不清就裁近或换图
- 禁止项：假手机框 + 糊 UI；整页生图假界面冒充作品；贴纸墙式多图无主次

### T-004 · 章节大数字留白
- 来源参考：种子（通用作品集）
- 作用层：排版氛围
- 适用场景：目录、章节分隔、案例序号页
- 做法：大数字或短章节名 + 大量留白；章节标识位置全册固定；字重对比清晰
- 禁止项：插画堆目录；宫格图标墙当目录；每章换一套皮肤

### T-005 · 中性底 + 单点缀色
- 来源参考：种子（通用作品集）
- 作用层：色彩 / 背景
- 适用场景：全册默认
- 做法：大面积白 / 浅灰 / 暖灰 / 近黑其一；点缀色 ≤ 1，用于强调、页码、关键标注；作品截图可带原品牌色但不另开第二套版式彩虹
- 禁止项：大面积蓝紫 / 粉紫假渐变；多点缀色互抢；霓虹描边当强调

### T-006 · 光滑柔光底（禁颗粒 / 禁雷达线）
- 来源参考：种子（通用作品集）
- 作用层：背景 / 材质 / 光影
- 适用场景：封面氛围、章节页、需要轻氛围但不抢图的页
- 做法：可命名的柔雾或极淡单色相光晕；强度以「几乎看不见但去掉会更假」为准；全册光向一致
- 禁止项：film grain / 砂面噪点当质感；同心圆 / 雷达弧 / 地形细线装饰底；满屏 glow

### T-007 · 标注式正文而非作文式正文
- 来源参考：种子（通用作品集）
- 作用层：排版氛围
- 适用场景：过程页、结果页、设计说明页
- 做法：字服务图——短标签、一行结论、必要约束；演讲者口述补全；一页一事
- 禁止项：段落堆进 PPT；满页 Synergy / Elevate / Next-gen；把简历长文贴进幻灯片

### T-008 · 页边距与栏系统
- 来源参考：种子（通用作品集）
- 作用层：排版 / 结构
- 适用场景：全册（Figma / Keynote / Slides 母版）
- 做法：锁定画布 1920×1080（或 1440×810 稿）；统一页边距、栏宽、标题区、页码、章节标识；换页只换内容不换坐标系
- 禁止项：每页边距漂移；标题区上下乱跳；页码有时有有时无

### T-009 · 过程三联不超过三
- 来源参考：种子（通用作品集）
- 作用层：层次 / 排版
- 适用场景：探索、迭代、方案对比、流程说明
- 做法：最多 3 个信息块；图大于字；块与块对齐；有主次（可一大两小）
- 禁止项：四格以上贴纸墙；每块厚阴影卡堆叠；字多过图

### T-010 · 结果指标少而真
- 来源参考：种子（通用作品集）
- 作用层：排版 / 验收
- 适用场景：结果页、影响页、复盘页
- 做法：指标少（建议 ≤ 3）、可口述来源或边界；结果真图优先；数字字号可大但标签退后
- 禁止项：假仪表盘 / 假百分比墙；空洞 HUD；用营销 Before/After 海报替代可阅读说明

### T-011 · 系列感先于单页炫技
- 来源参考：种子（通用作品集）
- 作用层：全册系统
- 适用场景：整本 Deck 改版、多案例拼接
- 做法：先锁母版系统再装饰；同字号阶梯、同强调色用法、同截图处理方式（圆角/阴影若用则统一且克制）
- 禁止项：每页换皮肤；单页特效破坏全册节奏；用装饰掩盖缺作品图的弱页

### T-012 · 封面测试与减页诚实
- 来源参考：种子（通用作品集）
- 作用层：验收 / 叙事表达层
- 适用场景：封面定稿、整册终检、素材不足时
- 做法：去掉姓名后仍应像「设计作品集」；没有真实作品图就减页，不靠插画充数
- 禁止项：招商科技封面皮；空洞炫技页替代作品；假 UI 充数

- 禁止项：把整条长页缩成一张 PPT 糊图

### T-021 · 垫图只做可命名柔底

- 作用层：背景 / 材质
- 适用场景：封面/章节/案例页需要氛围但不抢截图时

### T-022 · 设计分析页讲结构不堆界面
- 来源参考：`252:1793` section/10
- 作用层：排版 / 叙事表达层
- 适用场景：作品集方法论、信息架构说明、版式原则页
- 做法：用模块卡 / 简图说明「怎么拆、怎么读」；一页一分析点
- 禁止项：把分析页做成无关 UI 瀑布；抄别人项目结论

### T-023 · 方案分析一页一决策
- 来源参考：`252:1793` section/11
- 作用层：排版 / 层次
- 适用场景：方案对比、取舍说明、关键决策页
- 做法：决策点一句 + 必要图示；字是标注；可与过程框架区互通但更偏「为什么选」
- 禁止项：一页塞多个互不相关方案；营销招贴腔

### T-024 · 目录页居中包装（大数字 + 分栏视觉锚）
- 来源参考：`252:1793` section/02（目录/章节样本）+ 用户目录改稿实战
- 作用层：排版 / 材质 / 插画（辅助锚）
- 适用场景：作品集目录页、章节总览
- 做法：整页内容块水平垂直居中；顶栏 `CONTENTS` + 中文短题 + 单点缀短线；三栏（或少栏）等宽包装卡；每栏顶部放**一枚**可命名抽象视觉锚（非假 UI）；栏内大数字水印 + 短章节名 + 细线 + 标注式条目；近黑底可用克制蓝雾垫图；点缀色 ≤ 1（蓝）
- 禁止项：裸字左飘不居中；紫玻璃拟态墙；无视觉锚的纯文字目录装成熟作品集；宫格图标墙；每栏换一套皮肤

### T-025 · 封面通透蓝 3D 场景 + 角色句
- 来源参考：`252:1793` section/01（玻璃环/软萌角色样本）+ 封面改稿实战
- 作用层：主视觉 / 排版 / 材质
- 适用场景：作品集封面、Demo Deck 首页（视觉/体验设计师气质）
- 做法：浅通透蓝柔雾舞台（非死黑）；主锚为**可命名通透材质**（亚克力/玻璃折射冰蓝环球）± 软比例萌角色；左侧 EXPERIENCE DESIGNER / 体验设计师 + 姓名 + PORTFOLIO；点缀色 ≤ 1 且偏发光冰蓝；联系信息底栏标注式；封面测试：去姓名仍像设计作品集
- 禁止项：哑光铬环假科技；紫胶囊；主板立方体堆；塑料 AI 人贴纸墙；整页一次生图糊封面


### T-026 · 学习用户改稿：文案纪律 + 不覆盖其排版
- 来源参考：用户改稿 `210:1793` + 纠偏「学习不是改目录」（2026-07-28）
- 作用层：排版 / 协作流程 / 验收
- 适用场景：作品集封面、目录、演讲页；尤其用户已手工调过的页
- 做法：从用户稿学——一行放得下就一行；非逻辑列举不用圆点；去掉无信息重复；目录视觉锚用**卡片内留白方图**而非通栏硬裁；分隔线/溶底等结构件可保留。用户说「学习/对比」时**只读记录，不重排其间距字阶**
- 禁止项：把「学习」理解成覆盖用户已调舒适的排版；方图强行拉通栏 FILL；一刀切删分隔线/页标；条目硬拆行；无信息中英双写

### T-027 · 目录三态（竖列表 / 三栏卡 / 大数字水印）
- 来源参考：`252:1793` section/02（2026-07-28 重整理增量）
- 作用层：排版 / 结构
- 适用场景：作品集目录、章节总览、过渡页
- 做法：在三种成熟目录模式里选一种全册锁定——① 竖列表 + 细线 + 页码；② 左短题 + 右三栏包装卡；③ 巨型 CONTENTS/数字水印 + 短章名。标题区位置固定；条目标注式、一行能放下就一行
- 禁止项：三种混用在同一页互相抢戏；图标宫格墙当目录；每章换一套目录皮肤

### T-028 · 目录视觉锚用 inset 方图 + 舒适组距
- 来源参考：`252:1793` section/02 + 用户目录稿 `346:1793`（前序 `318:1793`）
- 作用层：排版 / 层次
- 适用场景：三栏/多栏目录包装
- 做法：视觉锚放在卡内上方，四周留白（inset）+ 可选溶底；不拉通栏硬裁；组内紧、组间松；结构分隔线可保留；方图/3D 为可命名抽象物（球、层叠板、飘带等），非假 UI；大数字可作淡水印垫在文案后
- 禁止项：方图 FILL 拉满栏宽；为「满」而挤掉舒适间距；用装饰插画堆替代章节数字/短名

### T-029 · 结果页大数字少而真（可并置真机）
- 来源参考：`252:1793` section/07（2026-07-28 第二轮补齐）
- 作用层：排版 / 验收
- 适用场景：结果页、影响页、验证页
- 做法：指标 ≤ 3、字号可大但标签退后；三种常用编排——横排结论块下挂百分比、浅底少点缀色指标、上指标下真机并置；数字需可口述来源或边界
- 禁止项：假仪表盘墙；空洞 HUD；营销 Before/After 海报替代可阅读说明

### T-030 · 深色拟物工位封面：纸稿 + 发光厚砖 + 暖冷光（无人名）
- 来源参考：用户他方生图封面 05/06 + `252:1793` section/01
- 作用层：主视觉 / 材质 / 排版
- 适用场景：作品集封面要一眼抓住、偏 C4D 拟物工位时
- 做法：满幅夜景工位；材质混合——木/哑光键帽、**纸面线稿**、**厚圆角自发光亚克力工具砖**；暖台灯 + 冷蓝紫环境光；轻趣味点缀（多肉/毛球）不抢主锚；左栏大字阶（年号+体验设计+DESIGN PORTFOLIO）；不放姓名
- 禁止项：空软糖单色场景；无纸面触感的塑料堆；满屏无焦点杂物；联系方式墙

### T-031 · RichClay 封面：混材密度，禁白模空台
- 来源参考：用户反馈 Clay A–D「太简单 / 没质感 / 像白模」+ cases/`cover-richclay-2026-07-28.md`
- 作用层：主视觉 / 材质 / 光影
- 适用场景：暗底拟物封面要保留 claymorphism，但拒绝空模感
- 做法：单帧可命名材质 ≥ 4（soft-touch SSS、磨砂亚克力边、金属、纸纤维/木纹、毛毡等）；主锚 + 次级道具有前后景与接触阴影；暖局部光 × 冷环境；左栏字阶不变；无软件 logo / 无人名
- 禁止项：单色圆角块面空台；只有一种哑光塑料；写实房间回潮；为「满」而塞软件图标砖

### T-032 · 封面品味闸门：单主锚 + 电影层次，禁粘土桌面玩具
- 来源参考：`252:1793` section/01 + 用户全删 Clay/RichClay（「好丑」）+ cases/`cover-taste-gate-2026-07-28.md`
- 作用层：主视觉 / 验收 / 生图
- 适用场景：任何作品集封面出图前
- 做法：出图前自问四条——①会不会像又一张 AI 设计师桌面？②第一眼主锚能否三词说清？③暗空字区是否干净？④与 section/01 精选并排是否敢放？全过才进稿。优先：光幕揭层 / 单材质舞台灯碑 / 极端宏观产品；层次靠前景虚+主锚实+暗空底；材质玻璃/金属/自发光反差
- 禁止项：多肉便签洞洞板可爱堆；白模空台；软件 logo 砖；左栏模板硬贴在杂物桌上当「完成」

### T-033 · 封面跟目录同系：字锚 + 单枚抠图，禁整页生图糊封面
