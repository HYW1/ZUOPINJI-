## 根因

一直在「换一张更炫的整页生图」，没有跟你已留下的 **目录页系统** 对齐。  
Skill 默认封面其实是：**疏朗中性舞台 + 字阶 + 单锚**，不是 Midjourney 桌面/光幕。

## 新规则（T-033）

1. 封面与目录同系：同一柔雾底、同一点缀蓝、同一 `01 / PORTFOLIO` 底栏  
2. **字是主锚**（或字 + 一枚抠图抽象物）  
3. 抽象物只做 **透明抠图单件**，禁止整页场景糊图当封面  
4. 出图前问：和目录并排是否像同一本 Deck？不像 → 杀掉
