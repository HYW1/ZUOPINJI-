# 品味闸门：封面「好看」判定（2026-07-28）

用户全删 RichClay / Clay 等稿：仍丑。根因不是「道具不够多」，而是**没有层次与主锚**，像 Midjourney 粘土桌面玩具。

## 参考板 01 告诉我们什么叫好看

- **一主锚**：能用三个词说清（光幕揭层 / 亚克力灯碑 / 键帽宏观）
- **前后景**：前景虚、主锚实、背景暗空；反射或体积光可选
- **材质可命名且反差**：磨砂玻璃/金属细边/自发光/哑光曲面 — **不是**单一 soft clay
- **字与图有空间关系**：字落在暗空或与主锚叠层，不是贴一张「左栏模板」在杂物桌上
- **禁止**：多肉便签洞洞板堆、白模空台、软件 logo 砖、满屏可爱道具

## 自评流程（出图前必过）

1. 这张会不会像「又一张 AI 设计师桌面」？是 → 杀掉重做  
2. 第一眼落点是不是唯一？否 → 减道具  
3. 左/暗区有没有干净字区？无 → 改构图  
4. 和 section/01 精选并排，我会不会害羞？会 → 不进稿
