# 纠偏：Clay 白模 → RichClay 混材密场景（2026-07-28）

用户：Clay A–D 太简单、没质感、像白模。

## 失败点

- 单色 soft-touch 块面过多，材质说不出名字
- 道具过稀，舞台像空模
- 缺暖冷光对比与边缘细节（磨砂边、纸纤维、金属螺钉等）

## 做法

保持 **C4D 拟物 / claymorphism**（非写实夜办公室），但强制：

1. **可命名混材 ≥ 4**：soft-touch SSS、磨砂亚克力边、金属灯臂、纸纤维/木纹、毛毡球等
2. **密度**：主锚 + 3–6 个次级道具，有前后景与接触阴影
3. **暖灯 × 冷环境**，屏/键局部自发光
4. **无软件 logo**、无人名、无人像
