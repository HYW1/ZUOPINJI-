## 可迁移规则（作品集 PPT）

1. **字不能太小**：投屏页正文/条目建议 ≥ 24–28；眉题 ≥ 18–20；勿用 12–14 当正文信息。
2. **一行能放下就放一行**：可合并的短条目不要硬拆多行（例：`超级助理Newtab` + `体验优化` → 一行）。
3. **非逻辑/非举例不用点**：目录条目若只是并列项目名，直接排字，不要圆点子弹。
4. **去掉没必要的装饰**：水印大数字、重复页脚、空壳节点、仅为装饰的分割线/顶条，优先删。
5. **内容不重复**：中英双写仅保留有信息增量的；空 frame / 删剩文案节点清掉。
6. **图片填充**：卡片视觉区用 FILL 铺满并裁到主体可读；角色全身主视觉优先 FIT，避免砍头。
7. **间距**：组内紧、组间松；删装饰后靠间距与字阶分层，不靠描边墙。
