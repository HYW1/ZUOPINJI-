# 反 AI 模板快速检查（作品集 PPT）

改稿前后各扫一遍。任一项为「是」→ 必须改。

## 封面 / 首屏

- [ ] 是否大面积蓝紫 / 粉紫假渐变当封面？
- [ ] 是否只有空洞大词 + 装饰、没有真实作品锚点（或刻意留白舞台）？
- [ ] 是否堆了图标行、胶囊标签丛、假数据统计条？
- [ ] 去掉姓名后，是否更像「科技公司招商 PPT」而非设计作品集？

## 结构与版式

- [ ] 是否每一段文案都包在厚阴影卡片里？
- [ ] 是否一页多事、段落堆进幻灯片？
- [ ] 是否全册页边距 / 标题区 / 页码不统一（每页换皮肤）？
- [ ] 是否「Before / After」做成营销对比海报，而非可阅读设计说明？

## 特效与材质

- [ ] 是否玻璃拟态多层叠加？
- [ ] 是否用无意义 glow / 外发光 / 霓虹描边制造「高级感」？
- [ ] 是否用同心圆 / 雷达弧 / 地形细线当背景装饰？
- [ ] 是否用颗粒感 / film grain / 砂面噪点冒充质感？

## 素材与作品真实性

- [ ] 插画是否像通用 AI 贴纸（塑料人、漂浮礼盒、空洞 3D）？
- [ ] 是否假手机框 + 模糊看不清的界面冒充作品？
- [ ] 是否一次生成整页 / 整本 PPT 糊图当成品？
- [ ] 文字是否烧进主视觉导致无法替换？
- [ ] 是否没有真实作品图却靠插画充数？

## 文案腔（表达层）

- [ ] 是否满页英文废话大词（Synergy / Elevate / Next-gen）无信息？
- [ ] 是否结果页堆假仪表盘 / 假百分比？

## 质感来源

- [ ] 质感是否靠特效堆砌，而不是层次 / 材质 / 排版节奏 / 一页一锚点？

全部为「否」才进入终验收。
