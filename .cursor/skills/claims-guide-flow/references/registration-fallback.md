# 仅挂号 · 双兜底

## 场景定义

用户**仅挂号、尚未产生可报销费用**时，不进入材料上传主链，进入「就医服务」兜底页：确认保单仍有效，并给出**且仅有两个**后续出口。

## 两个兜底（产品定义）

| # | 产品意图 | 底栏文案（demo 落地） | 按钮层级 |
|---|---|---|---|
| 1 | 精准查询能不能赔 | `查查能不能赔` | 主按钮 |
| 2 | 理赔申请协助 / 规则说明 | `了解报销规则` | 次按钮 |

禁止：

- 增加第三条同级主路径  
- 「可赔概率 20%」等未在 demo 出现的量化承诺  
- 把疾病查查、规则说明、客服、商城入口平铺成宫格  

## 页面模块（与 demo 对齐）

### 1. 蓝底结论卡

- 眉标：`理赔向导`（可无 emoji）  
- 标题：`你的保单继续保障中`（Status Title 40 Medium）  
- 说明：`之前理赔过不影响后续，本次就医费用可以继续申请报销`  

### 2. 保单状态确认

- 标题 + 简述  
- 内嵌保单条：`好医保·长期医疗险`  
- 状态行：`保障中 · 年度免赔额已抵扣 ¥6,500`  
- 提示（Notice 色）：自费部分可累计抵扣剩余免赔额  

数字以 demo / 业务数据为准，勿擅自改免赔额。

### 3. 后续服务已准备就绪

引导句：`安心看病，后面的事交给我们`  

三条服务（保持三条，不扩写）：

1. 看完病结算后，自动识别可报销的就医记录  
2. 电子发票出来后，提醒你申请报销  
3. 材料怎么准备、去哪里拿，理赔向导全程引导  

### 4. 底栏

- 左：次按钮 `了解报销规则`  
- 右：主按钮 `查查能不能赔`  
- 使用 Button 组件 L 尺寸实例；宽度均分，间距 16
