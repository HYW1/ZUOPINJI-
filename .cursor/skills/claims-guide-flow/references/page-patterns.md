# 页面结构模板

所有模板默认：`TopBar 176` + 内容区 + 固定底栏；页宽 750，内容 718 / padding 16；卡片圆角 24，内卡 16；字色遵循 TextPrimary 80% / Secondary 60% / Tertiary 40%。

## 1. 授权发现

```text
TopBar
结论/任务句（获取发票 / 可快捷申请）
就医记录列表（医院 / 时间 / 金额 / 票号）
（可选）授权说明浮层：拒绝 | 允许
底栏：取消 | 下一步
旁路：没就医，先查查疾病能不能赔
```

要点：先告诉用户系统能帮他做什么，再展示记录。

## 2. 就医记录选择

```text
TopBar
任务句：以下可以快捷申请理赔
可选列表（单选或多选按产品规则）
底栏：取消 | 下一步
```

要点：列表项结构统一，金额用数字字体；合并提示若存在，放在列表上方一句说明，不要散落在每张卡上。

## 3. 选择保单（步骤）

```text
TopBar：理赔向导
步骤：第 2 步 / 3
标题：选择用于报销的保单
保单卡片列表
  - 名称 +「推荐」标签（若适用）
  - 保障范围
  - 推荐理由（一句，基于发票类型）
合规注：*推荐仅基于发票类型初步判断…
底栏：上一步 | 下一步
```

要点：推荐理由可解释、可推翻；不作承保承诺。

## 4. 确认就医情况（步骤）

```text
TopBar：理赔向导
步骤：第 3 步 / 3
标题：确认就医情况
事故类型*：疾病 | 意外
就医类型*：住院 | 门诊手术 | 特殊门诊 | …
理赔材料预告：报销需准备 N 项
  材料行：名称 + 必需 + 示例 + 一句说明
底栏：上一步 | 下一步
```

要点：材料预告是预期管理，不是上传完成态。

## 5. 材料核对结果（诊断页）

见 [materials-diagnosis.md](materials-diagnosis.md)。

骨架：

```text
TopBar：理赔向导
结论条（成功绿 / 提醒橙，按状态）
三列统计：已保存 | 识别成功或未上传 | 待处理
模块：已传材料
帮助行：材料准备有困难？咨询理赔向导
材料分组列表（必传 + 缩略图/示例）
底栏主按钮：与结论一致的下一步
```

## 6. 仅挂号兜底（就医服务）

见 [registration-fallback.md](registration-fallback.md)。

骨架：

```text
TopBar：就医服务
蓝底结论卡：你的保单继续保障中
白卡：保单状态确认 + 内嵌保单信息 + 免赔提示
白卡：后续服务已准备就绪 + 3 条编号服务
底栏：了解报销规则（次）| 查查能不能赔（主）
```

## 7. 疾病查查

```text
TopBar：疾病查查
说明：请选择你关注的疾病（可多选）
搜索框
疾病标签云 / 列表
底栏：查查能不能赔（或等价主按钮）
```

## 8. 疾病查查结果

```text
TopBar
对象摘要（如：母亲*洁 若患甲状腺癌）
结论：XX 可以申请理赔 / 什么情况下可赔
条件列表：确诊时间 / 既往症 / 医院要求…
关联保单信息
合规：以上为条款参考，最终以保险公司为准
（可选）计划就医/已就医后续服务入口
```

## 卡片使用规则（本流程）

**用卡片**：保单对象、材料分组、兜底中的「状态确认 / 后续服务」、结论色块。  
**不用卡片**：单句说明、步骤指示、底栏、单纯分割线内容。  
**禁止**：每一段说明各自一张悬浮卡；英雄区再叠 promo 贴纸。
