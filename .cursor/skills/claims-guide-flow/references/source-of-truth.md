# 真源优先级与文件坐标

## 真源优先级

改稿或补页时，按此顺序取舍：

1. **用户当次指令**（明确说改什么 / 不改什么）
2. **用户粘贴的 demo 图、产品截图、标注图**（文案与模块结构以此为准）
3. **本仓库 claims-guide-flow skill**（场景、模板、排序、纪律）
4. **当前 Figma 画板中已定稿的同场景页面**（视觉与组件用法）
5. **支付宝 APP 基础设计系统**（token、组件 key、字号间距）
6. **通用设计灵感**（最后手段；不得覆盖以上）

若 demo 图是位图（不可编辑文字），仍以图中可见文案为准抄写，不要「润色成更好听」。

## Demo 输入约定

用户常以图片喂内容，而不是可复制文本。处理方式：

1. `get_screenshot` / 读取图片描述，抽出标题、统计、列表项、按钮文案。  
2. 结构对齐图片模块顺序。  
3. 视觉落到支付宝 token（字号、间距、圆角、主次按钮），不要 1:1 临摹位图像素瑕疵。  
4. 不确定处标「待确认」，不要编造业务规则（尤其可赔概率、免赔计算细节以外的数字）。
