# 终验收表（作品集 PPT / Demo Deck）

用于整册或约定页范围完成后的勾选。单页过程截图另存，不替代本表。

## 观感

- [ ] 第一眼不像「AI 模板 PPT / 招商科技皮」
- [ ] 每页有明确主视觉锚点（一页一事）
- [ ] 装饰没有抢走真实作品信息
- [ ] 通过封面测试：去姓名仍像设计作品集

## 系统与质感来源

- [ ] 画布为 1920×1080（或约定同比例稿）
- [ ] 全册页边距 / 标题区 / 页码 / 章节标识 / 字号阶梯一致
- [ ] 大面积中性底；点缀色 ≤ 1；无廉价大面积蓝紫假渐变
- [ ] 质感来自层次 / 材质 / 排版节奏，而非 glow / 玻璃堆 / 颗粒滤镜

## 作品真实性与可维护性

- [ ] 界面截图 / 过程稿真实可读；无假 UI 糊图
- [ ] 过程页信息块 ≤ 3；结果指标少而真
- [ ] 生图按单张完成并逐张校验后嵌入（无整页糊）
- [ ] 素材可替换、可复用（无烧字、无一次性整页拼图）

## 过程证据

- [ ] 关键改动页有过程截图 / 导出
- [ ] 有整册关键页前后对比（至少封面 + 案例开场 + 过程 + 结果）

## 可迁移性

- [ ] 本次学到的技巧已用「可迁移」语言记入 `learned-techniques.md`（不绑死单一项目）

全部勾选方可交付。
