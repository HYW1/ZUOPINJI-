### T-001 · 一页一锚点
- 来源参考：种子（通用作品集）
- 作用层：主视觉 / 排版
- 适用场景：封面、案例开场、结果页、任意演讲页
- 做法：每页只保留一个第一眼落点（封面人 / 项目主图 / 关键界面 / 过程物，二选一为主）；其余退为衬托；标题与标注不与锚点抢面积
- 禁止项：双主锚（大插画 + 大截图同时抢戏）；用装饰物冒充锚点

### T-002 · 疏朗封面舞台
- 来源参考：种子（通用作品集）
- 作用层：排版 / 背景
- 适用场景：封面、章节页、过渡页
- 做法：极克制中性底 + 姓名/角色一句 + 一个真实作品锚点或留白舞台；大留白制造投屏气场
- 禁止项：紫渐变科技皮；图标行 + 胶囊标签丛 + 假统计条塞满封面；满页英文废话大词

### T-003 · 真截图压过装饰
- 来源参考：种子（通用作品集）
- 作用层：摄影或截图 / 层次
- 适用场景：案例开场、过程页、结果页
- 做法：界面 / 动效帧 / 过程稿必须真实可读；装饰与材质只做衬托；模糊看不清就裁近或换图
- 禁止项：假手机框 + 糊 UI；整页生图假界面冒充作品；贴纸墙式多图无主次

### T-004 · 章节大数字留白
- 来源参考：种子（通用作品集）
- 作用层：排版氛围
- 适用场景：目录、章节分隔、案例序号页
- 做法：大数字或短章节名 + 大量留白；章节标识位置全册固定；字重对比清晰
- 禁止项：插画堆目录；宫格图标墙当目录；每章换一套皮肤

### T-005 · 中性底 + 单点缀色
- 来源参考：种子（通用作品集）
- 作用层：色彩 / 背景
- 适用场景：全册默认
- 做法：大面积白 / 浅灰 / 暖灰 / 近黑其一；点缀色 ≤ 1，用于强调、页码、关键标注；作品截图可带原品牌色但不另开第二套版式彩虹
- 禁止项：大面积蓝紫 / 粉紫假渐变；多点缀色互抢；霓虹描边当强调

### T-006 · 光滑柔光底（禁颗粒 / 禁雷达线）
- 来源参考：种子（通用作品集）
- 作用层：背景 / 材质 / 光影
- 适用场景：封面氛围、章节页、需要轻氛围但不抢图的页
- 做法：可命名的柔雾或极淡单色相光晕；强度以「几乎看不见但去掉会更假」为准；全册光向一致
- 禁止项：film grain / 砂面噪点当质感；同心圆 / 雷达弧 / 地形细线装饰底；满屏 glow

### T-007 · 标注式正文而非作文式正文
- 来源参考：种子（通用作品集）
- 作用层：排版氛围
- 适用场景：过程页、结果页、设计说明页
- 做法：字服务图——短标签、一行结论、必要约束；演讲者口述补全；一页一事
- 禁止项：段落堆进 PPT；满页 Synergy / Elevate / Next-gen；把简历长文贴进幻灯片

### T-008 · 页边距与栏系统
- 来源参考：种子（通用作品集）
- 作用层：排版 / 结构
- 适用场景：全册（Figma / Keynote / Slides 母版）
- 做法：锁定画布 1920×1080（或 1440×810 稿）；统一页边距、栏宽、标题区、页码、章节标识；换页只换内容不换坐标系
- 禁止项：每页边距漂移；标题区上下乱跳；页码有时有有时无

### T-009 · 过程三联不超过三
- 来源参考：种子（通用作品集）
- 作用层：层次 / 排版
- 适用场景：探索、迭代、方案对比、流程说明
- 做法：最多 3 个信息块；图大于字；块与块对齐；有主次（可一大两小）
- 禁止项：四格以上贴纸墙；每块厚阴影卡堆叠；字多过图

### T-010 · 结果指标少而真
- 来源参考：种子（通用作品集）
- 作用层：排版 / 验收
- 适用场景：结果页、影响页、复盘页
- 做法：指标少（建议 ≤ 3）、可口述来源或边界；结果真图优先；数字字号可大但标签退后
- 禁止项：假仪表盘 / 假百分比墙；空洞 HUD；用营销 Before/After 海报替代可阅读说明

### T-011 · 系列感先于单页炫技
- 来源参考：种子（通用作品集）
- 作用层：全册系统
- 适用场景：整本 Deck 改版、多案例拼接
- 做法：先锁母版系统再装饰；同字号阶梯、同强调色用法、同截图处理方式（圆角/阴影若用则统一且克制）
- 禁止项：每页换皮肤；单页特效破坏全册节奏；用装饰掩盖缺作品图的弱页

### T-012 · 封面测试与减页诚实
- 来源参考：种子（通用作品集）
- 作用层：验收 / 叙事表达层
- 适用场景：封面定稿、整册终检、素材不足时
- 做法：去掉姓名后仍应像「设计作品集」；没有真实作品图就减页，不靠插画充数
- 禁止项：招商科技封面皮；空洞炫技页替代作品；假 UI 充数

### T-013 · 16:9 疏朗封面公式（参考强化）
- 来源参考：`252:1793` section/01
- 作用层：排版 / 主视觉
- 适用场景：作品集封面、Demo Deck 首页
- 做法：中性底 + 姓名/角色一句 + 单一真实作品锚点（或刻意空白舞台）；页边距大于内容区
- 禁止项：紫渐变招商皮；图标行/胶囊/假统计条塞满封面

### T-014 · 超大章节数字换插画密度
- 来源参考：`252:1793` section/02
- 作用层：排版氛围
- 适用场景：目录、章节分隔、案例序号
- 做法：一位或两位大数字 + 短章节名 + 大量留白；全册章节标识位置固定
- 禁止项：插画堆目录；宫格图标墙；每章换皮肤

### T-015 · 主屏 + 一枚细节层（有限叠景深）
- 来源参考：`252:1793` section/03–04
- 作用层：截图 / 层次
- 适用场景：案例开场、关键功能页
- 做法：底层完整可读主界面；最多再叠 1 枚前景细节（弹层/局部）；短软影；真图可辨
- 禁止项：多层假手机框墙；模糊不可读 UI；装饰插画替代真图

### T-016 · 细线圆点标注，不做作文
- 来源参考：`252:1793` section/04–05
- 作用层：排版
- 适用场景：过程说明、设计决策标注
- 做法：短标签 + 细 callout 线/圆点；字服务图；一页一事
- 禁止项：段落堆进幻灯片；满页英文废话大词

### T-017 · 长案例页拆成多页一事
- 来源参考：`252:1793` 多张竖向 Behance 长页
- 作用层：叙事表达层 / 结构
- 适用场景：把网页式案例落地为 1920×1080 Deck
- 做法：学其模块节奏与锚点，拆成封面/开场/过程/结果多页；每页只保留一个锚点
- 禁止项：把整条长页缩成一张 PPT 糊图

### T-018 · 深色方案仍克制点缀与光
- 来源参考：`252:1793` section/02–03 深色样本 + section/08
- 作用层：色彩 / 光影
- 适用场景：深色 Demo Deck
- 做法：近黑底可；点缀色 ≤ 1；高光局部；材质可命名
- 禁止项：满屏 glow / 霓虹描边 / 彩虹棱镜当默认皮

### T-019 · 母版坐标系先于单页炫技
- 来源参考：`252:1793` 全册对照（强化 T-008 / T-011）
- 作用层：全册系统
- 适用场景：多案例拼接、整本改版
- 做法：先锁页边距、标题区、页码、字号阶梯、强调色；再逐页换内容
- 禁止项：每页换边距/标题栏位置

### T-020 · 反面区分区即验收闸门
- 来源参考：`252:1793` section/08
- 作用层：验收
- 做法：改稿前后对照删除紫渐变墙、卡片堆、假 UI、贴纸墙、假仪表盘
- 适用场景：每次改稿前后
- 禁止项：无
