# 封面改稿笔记 · 通透蓝 3D 场景（2026-07-27）

## 用户纠偏
- 上一版暗底哑光金属环「太丑」；蓝不够通透
- 要更偏视觉设计师气质、可萌一点、3D 场景感更强
- 参考板 `section/01` 里的蓝是玻璃折射式通透，不是科技紫/哑光铬

## 参考可学（section/01）
1. **通透蓝材质**：亚克力/玻璃环与球体有折射与柔高光，背景浅灰或浅蓝雾，空气感强
2. **一页一主锚**：3D 场景独占一侧，字阶不与主锚抢面积
3. **萌而不贴纸**：软比例角色 + 少道具几何体，材质对比（软布料 vs 透玻璃）
4. **不要学**：紫胶囊标题、主板立方体堆、整页假 UI、满屏 glow
