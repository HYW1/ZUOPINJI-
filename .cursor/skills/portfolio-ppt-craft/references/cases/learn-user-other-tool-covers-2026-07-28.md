# 学习用户他方生图封面 05/06（2026-07-28）

用户用其他产品生成的两张封面作为质感标杆。只学语言，不整页抄构图。

## 可学技巧

1. **混合拟物材质**：木桌/哑光键帽 + **纸面线稿**（铅笔感、折痕）+ **厚圆角自发光亚克力块**（工具图标实体化）  
2. **暖冷对打光**：台灯钨丝暖 + 屏/图标冷蓝紫；短软接触影 + 可控 bloom  
3. **生活化密度**：多肉、笑脸毛球、笔、洞洞板图纸 — 趣味点缀，不抢主锚  
4. **主锚清晰**：左稿本/右图标簇，或键鼠+屏+图标三角  
5. **左栏大字阶**：年号 + 作品集 + DESIGN PORTFOLIO；底栏细标签  

## 不要硬抄

- 原样 Ps/Ai/Sketch logo 墙（可改成抽象色块工具砖，或少量抽象化）  
- 烧死在图里的联系方式/长英文鸡汤  
- 无焦点的杂乱堆砌  

## 对我稿的纠偏

此前偏：空、单色、软糖玩具、缺纸面与实体发光砖。  
应对齐：纸稿触感 + 发光厚块 + 暖灯办公夜景 + 轻趣味道具。
