# 封面场景选型（2026-07-28）

单元素 3D（环/板/晶体/带）已否决：太空漂浮物感强、缺空间层次。

## 参考 `01` 里可学的场景公式

1. **有空间坐标系**：地面/桌面/台座 + 前后景，不是黑洞里一个道具  
2. **有光的剧情**：暖灯 + 冷屏，或舞台追光 + 雾，光源可命名  
3. **多件相关物组成一场**：屏/层叠卡/路径同属一个叙事，不是贴纸墙  
4. **不要学**：漂浮 PS/AE/Figma logo 墙、假可读 UI、巨型键盘玩梗（易学生秀）
