## 生图闸门（入库）

出封面工位图前自检：

1. 工具砖是否 **等高同宽同厚**？否 → 重做  
2. 键盘 / 键鼠是否像 **Win 厚机械 / 游戏 RGB / 橙 Esc**？是 → 重做；优先 MacBook 或 Space Gray Magic Keyboard  
3. 第一眼是否像「低端 PC 桌面棚拍」？是 → 重做  
4. 亚克力是否有 **光学棱边折射**，而非廉价透明塑料壳？否 → 重做
