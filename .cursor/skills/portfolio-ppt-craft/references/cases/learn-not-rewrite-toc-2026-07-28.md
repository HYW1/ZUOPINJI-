# 学习纠偏 · 用户目录稿 vs 误改（2026-07-28）

> **指令澄清**：用户说「学习」，不是让改目录页。误改后用户明确：**不用改稿子了**。本文件只固化对比结论，**不再动 Figma 稿**。

## 对比结论（用户稿更舒服）

改稿前审计到的**用户目录稿**节奏：

| 项 | 用户稿 | 误改方向（更差） |
|----|--------|------------------|
| 标题 | CONTENTS 14 / 目录 56；标题区 gap 12 | 强行加大眉题、改舞台 padding |
| 卡片 | 480×560；正文 gap 32；条目 gap 24 | 重算卡片高、动间距 |
| 视觉图 | **方图 inset**（约 280×280，非整宽铺满） | 拉成 480 宽 FILL/裁切，主体变挤、变丑 |
| 结构件 | 保留分隔线、溶底、水印、页脚 | 当成「多余装饰」删掉 |
| 文案 | 已合并一行、已去圆点、已去英文重复 | 在用户已改基础上继续动刀 |

**学到的点**：

1. **学习 ≠ 重排**：用户已调过的间距/字阶/结构件，默认尊重；除非明确说「帮我改」。
2. **舒服的目录**：视觉锚是卡片内的**留白方图**，不是广告式通栏裁切。
3. **结构线 ≠ 废话装饰**：分隔线、轻溶底、轻页标可以服务节奏；不要一刀切删。
4. **文案纪律仍有效**（来自用户改法）：一行能放下就一行；非逻辑列举不用点；去掉无信息重复（如 C-END 双写）。
5. **字号**：用户目录里条目 28、章节名 40 已够投屏；不要用「一律加大」覆盖其层级。
