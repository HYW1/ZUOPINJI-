## 如何追加

1. 用户提供新参考（好样本 + 可选反面）
2. 按 `../templates/reference-breakdown.md` 的 7 问结构逐张/逐区拆解
3. 本目录新建文件，命名建议：`<来源简写>-<主题>.md`
4. 将可迁移技巧追加到 `../learned-techniques.md`（续编号）
5. 实战改稿笔记放 `../cases/`

## 拆解目标

- ✅ 可迁移的版式 / 材质 / 锚点 / 留白技巧  
- ❌ 抄袭他人项目内容或业务结论  
- ❌ 把别人的作品图当成本人作品
