## 分区拆解

### 参考区：01 封面与舞台

1. **主视觉锚点是什么**  
   - 单一 3D 材质物（通透冰蓝环/球、软雕塑）或软比例角色 + 玻璃道具；或空白舞台留给人像/作品。
2. **背景如何做氛围**  
   - 浅灰/浅蓝雾或近黑；强度低，让主锚浮起。
3. **层次怎么分**  
   - 前景：主锚；内容：姓名/角色/PORTFOLIO 字阶；背景：柔雾。
4. **材质与光影（可复用）**  
   - 通透亚克力/玻璃折射（非哑光铬）；软布料 vs 透玻璃对比；顶侧柔光。
5. **排版与留白**  
   - 左字右锚或疏朗居中；字阶清楚，不堆图标行。
6. **可迁移**  
   - 一页一锚；通透蓝优于科技紫；角色可萌但材质要可命名。
7. **不要学**  
   - 紫胶囊标题、主板立方体堆、角色贴纸皮、满屏 glow。

### 参考区：02 章节大数字与留白（本轮最重要增量）

1. **主视觉锚点是什么**  
   - **大数字 / CONTENTS 短名**；或三栏章节卡（数字 + 章节名 + 条目）。
2. **背景如何做氛围**  
   - 浅中性底或近黑；可有极淡 CONTENTS 水印；不抢字。
3. **层次怎么分**  
   - 标题区（CONTENTS/目录）→ 列表或三栏 → 可选页码；结构线可有。
4. **材质与光影（可复用）**  
   - 浅底深字 / 深底浅字皆可；章节卡可用轻底差，**卡内方图 inset 留白**，勿通栏硬裁。
5. **排版与留白节奏**  
   - 用户偏好型：左标题 + 右三栏；或竖列表细线+页码；组内紧、组间松。  
   - 条目一行能放下就一行；非逻辑列举不用圆点。
6. **可迁移**  
   - **T-027 目录三态**：① 竖列表+页码；② 左题右三栏卡；③ 大数字水印+短章名。  
   - 三栏卡用舒适间距与 inset 视觉，不重排用户已调节奏。
7. **不要学**  
   - 把学习理解成覆盖用户目录；图标宫格目录墙；条目硬拆行。

### 参考区：03 案例开场主视觉

1. **锚点**：一句钩子 + 主界面/主项目真图（可深可浅舞台）。  
2. **可迁移**：开场只留问题/角色一句 + 真图；禁标签丛。  
3. **不要学**：假仪表盘开场、双主锚抢戏。

### 参考区：04 真截图与标注

1. **锚点**：可读真截图；标注短、细线/圆点 callout。  
2. **可迁移**：图大于字；竖帧可作过程特写。  
3. **不要学**：假手机框糊 UI、作文式段落。

### 参考区：05 过程与框架

1. **锚点**：过程三联或清晰框架图。  
2. **可迁移**：≤3 信息块；探索对比可辨。  
3. **不要学**：空洞 glow 框架（进 08）。

### 参考区：06 字体层级与中性底

1. **可迁移**：字重阶梯 + 中性底；少装饰。  
2. **不要学**：满屏同粗细、装饰字体墙。

### 参考区：07 结果与指标

1. **可迁移**：指标少而真。  
2. **注意**：实测偏少，待用户补齐后再深拆。

### 参考区：08 反面教材

1. **作用**：出现即改闸门——霓虹 glow、雷达、假仪表盘、贴纸墙、营销招贴、AI 封面皮。  
2. **不要学**：整区任何「炫技默认解」。

### 参考区：09 背景垫图材质

1. **可迁移**：柔雾/细网格/流体作垫图，强度低于主锚。  
2. **不要学**：垫图当作品、人头贴纸垫图。

### 参考区：10 / 11

1. **10**：学版式与叙事拆页，不抄项目内容。  
2. **11**：一页一决策点；C/B 方案合区。
