## 垫图使用规则（强制）

- 垫图服务真作品截图，**不抢锚点**
- 材质可命名：柔雾、光滑渐变、细结构网格、流体绸面…
- 禁止：人像、动漫头像、金币盾标、贴纸墙当「质感」
- 强度以「几乎看不见但去掉会更假」为准（对齐 T-006）

## 可学增量（摘要）

1. 垫图用高键柔雾 / 低对比流体，比颗粒噪点更适合投屏  
2. 设计分析页用 Venn / 模块卡说明「怎么拆」，不是堆 UI  
3. 方案分析页一页一决策点；封面字效可极简单锚  

细节技巧仍以 `learned-techniques.md` 为准；本轮以入库整合为主。
