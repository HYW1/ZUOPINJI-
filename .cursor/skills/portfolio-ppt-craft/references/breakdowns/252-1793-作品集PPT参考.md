## 分区拆解（本轮重点）

### 01 封面与舞台（内容刷新）

1. **主锚三态（择一全册锁）**  
   - **通透角色/玻璃道具**（软比例 + 可命名折射材质）  
   - **桌面/场景舞台**（灯下空间 + 作品屏，一页一舞台）  
   - **字体海报单锚**（超大 PORTFOLIO / 年份，字即主锚）
2. **氛围**：浅雾或近黑柔光；强度让主锚浮起。  
3. **可迁移**：强化 T-025；一页一锚。  
4. **不要学**：紫胶囊、主板立方体堆、角色贴纸皮、满屏 glow（进 08）。

### 02 章节大数字与留白（内容刷新）

1. **目录三态仍成立**（T-027）：竖列表+页码；左题/顶题 + 三栏卡；巨型 CONTENTS/数字水印。  
2. **卡内视觉**：inset 方图 / 3D 抽象锚 + 溶底（T-028）；条目标注式、一行能放下就一行。  
3. **用户页 `346:1793` 对齐**：居中 CONTENTS+目录；三等分卡；球/层叠板/飘带抽象锚；淡蓝大数字；细分隔线；底栏 `01 / PORTFOLIO`；柔雾+CONTENTS 水印。  
4. **不要学**：覆盖用户已调间距；宫格图标墙；多点缀色互抢。

### 03 案例开场主视觉（+7）

1. **正学**：一句钩子 + 主界面真图（可倾斜/扇形手机，但真 UI 可读）。  
2. **慎用**：雷达/生态圈/多路径对比更偏 05/11——若落在 03，当「整理中」，开场页勿默认抄成框架墙。  
3. **不要学**：假仪表盘开场、双主锚。

### 04 / 05 / 06

- **04**：真截图 + 细线短标注（T-003 / T-016）。  
- **05**：过程 ≤3（T-009）。  
- **06**：字重阶梯 + 中性底。

### 07 结果与指标（+2，本轮可深拆）

1. **主锚**：少而真的大数字（≤3 为宜）。  
2. **三种可复用编排**  
   - 横排过程块 + 其下百分比  
   - 浅底大标题 + 少量橙点缀指标 + 可选短反馈气泡  
   - 上区指标、下区真机并置（结果有界面证据）  
3. **可迁移**：T-029。  
4. **不要学**：假仪表盘墙、空洞 HUD（进 08）。

### 08 反面教材（-11，更干净）

霓虹 glow / 雷达装饰 / 假仪表盘 / 贴纸墙 / 营销招贴 / AI 封面皮 —— **出现即改**（T-020）。

### 09 背景垫图（+3）

柔雾 / 光滑渐变 / 流体绸面 / 细结构网格；**强度低于主锚**（T-021）。  
勿把高饱和油彩流体当封面主锚。

### 10 / 11

不变：学版式与「一页一决策」，不抄项目内容。
