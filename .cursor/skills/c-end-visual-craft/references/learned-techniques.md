### T-001 · 一屏一锚点（可命名材质）
- 来源参考：section/01、05
- 作用层：主视觉 / 材质
- 做法：每屏一个主角物；能说出材质名；文案退到一侧或下方
- 适用：Hero、结果态、权益头图、空状态
- 慎用：多层玻璃叠罗汉；虹彩丝带铺满

### T-002 · 背景三层气雾
- 来源参考：section/02
- 作用层：背景 / 光影
- 做法：实底 → 大半径模糊色团 → 少量细节光/颗粒；氛围停在页头上 1/3
- 适用：支付宝系工具/服务页顶区
- 慎用：暗黑赛博光带；彩虹棱镜默认皮

### T-003 · 左信息 · 右主物
- 来源参考：section/01
- 作用层：排版 / 主视觉
- 做法：信息成组靠左，体积物靠右；主视觉周围留呼吸
- 适用：运营位、结果头图
- 慎用：主物烧字；两侧同时塞插画

### T-004 · 分层用一种手段
- 来源参考：section/04
- 作用层：光影 / 卡片
- 做法：浅色短软阴影；暗色边缘高光；勿阴影+霓虹+内发光叠满
- 适用：列表卡、会员卡、数据卡
- 慎用：霓虹描边卡片墙（section/10）

### T-005 · 卡片是容器不是段落框
- 来源参考：section/04 + 10
- 作用层：层次
- 做法：能用底色分区/分割线/留白完成的，不要包厚卡
- 适用：首页、详情、表单
- 慎用：每段话一张卡

### T-006 · 图标两档材质
- 来源参考：section/05（扩充后）
- 作用层：图标 / 插画
- 做法：宫格统一语言；Hero/空状态才升级玻璃或抛光
- 适用：入口宫格、成功/安全态
- 慎用：每个小入口重度玻璃；塑料 AI 贴纸人

### T-007 · 主物必须透明可叠（强制）
- 来源参考：section/05、09；实战反馈
- 作用层：材质 / 生图
- 做法：绿幕或干净底生成 → rembg/色键抠图 → 清边 → RGBA PNG → Figma `IMAGE+FIT`，禁止烘焙白底/云雾方板
- 适用：一切 Hero 3D（盾/心/文件夹/吉祥物）
- 慎用：未抠图直接贴；透明通道上再铺不透明底色

### T-008 · 疏朗留白 + 指标先行（纠正后）
- 来源参考：section/08 **新板**（非旧营销海报）
- 作用层：排版
- 做法：模块间大呼吸、组内紧；金额/分数/百分比极大，标签灰色退后；内边距按 8 栅格加码
- 适用：工具页、报告页、详情页
- 慎用：把旧 08 的全家福海报当留白范本；暗蓝霓虹大圆钮默认皮

### T-009 · 顶雾溶白 + 白岛长软影
- 来源参考：section/09 **扩充后**
- 作用层：背景 / 结构
- 做法：顶区极淡品牌雾溶入白；内容白岛用**页底色差 + 细描边**浮起（默认不加卡片投影）；列表用设计系统
- 适用：保险/服务/结果默认公式
- 慎用：照搬绿/金大面积主题墙

### T-010 · 反面即验收闸门
- 来源参考：section/10
- 作用层：验收
- 做法：对照删除霓虹描边、蓝紫墙、空洞 HUD、通用 AI 柱体礼盒、高饱和软 UI
- 适用：每次改稿前后
- 慎用：无

### T-011 · 3D 轻压卡片上沿做景深
- 来源参考：section/09
- 作用层：层次
- 做法：透明主物可轻微越过白卡上沿，制造前后景；必须已抠图
- 适用：结果头、保障头图
- 慎用：压住关键文案；未抠图的方板「假压边」

### T-012 · 摄影与 3D 勿双主锚
- 来源参考：section/09
- 作用层：主视觉
- 做法：头图以摄影或 3D 其一为主，另一退为辅或不用
- 适用：营销/保障头图
- 慎用：摄影墙 + 大 3D 同时抢第一眼

### T-013 · 极淡微纹理增触感
- 来源参考：section/08 新板
- 作用层：背景
- 做法：地形线级微纹理或细颗粒，强度以「几乎看不见但去掉会更假」为准
- 适用：高键浅色页头
- 慎用：贴图墙、强噪点、干扰正文

### T-014 · 营销群像仅限营销模块
- 来源参考：section/05（扩充后归位）
- 作用层：插画
- 做法：家庭/老人 3D 群像用于权益/情感海报；工具/表单/结果核验页改用单隐喻图标
- 适用：分流页面类型
- 慎用：工具页堆群像抢信息

### T-015 · 浅底座用光，不用道具
- 来源参考：用户改稿 `135:689` / `169:870`
- 作用层：主视觉 / 光影
- 做法：主物下方叠 1～2 个低透明、大模糊的浅蓝椭圆作落点；或资产内极浅环。禁止金币、纸张、文件夹角标凑「丰富」
- 适用：结果成功态、防护/核验 Hero
- 慎用：烤盘光圈方板；一堆漂浮道具

### T-016 · 成功态标题走品牌蓝
- 来源参考：用户改稿结果页
- 作用层：排版 / 色彩
- 做法：核验通过类主标题用品牌蓝大字（约 40），说明灰字退后；勿一律墨黑标题
- 适用：结果通过、开通成功
- 慎用：警告/失败态也套蓝

### T-017 · 语义符号匹配场景
- 来源参考：用户改稿医疗十字盾
- 作用层：主视觉
- 做法：医疗/就医结果优先十字或医疗隐喻；通用勾选盾慎用于医疗结果（易像安全 App 贴纸）
- 适用：选 Hero 符号时
- 慎用：所有成功态都复用同一勾选盾

### T-018 · 数字舞台两种轻量写法
- 来源参考：用户左右稿对比
- 作用层：层次
- 做法：A) 半透明磨砂条浮在顶雾上；B) 收进同一摘要白岛的浅灰内区。二选一，勿再套第三层厚卡
- 适用：结果摘要指标
- 慎用：白卡套白卡套灰卡

### T-019 · 主物要够大、要融进顶区
- 来源参考：用户左稿大尺寸十字盾
- 作用层：主视觉
- 做法：Hero 约占顶区视觉权重的一半；与顶雾同色温；可轻压卡沿。忌小图贴白卡右上角当角标
- 适用：运营向结果头
- 慎用：为「克制」缩到失去质感

### T-020 · 工具页容器要薄；3D 只留一处锚点
- 来源参考：用户改「补充材料」稿反馈（2026-07-27）
- 作用层：图标 / 容器
- 做法：表单/补材工具页**可以**保留头图一枚软 3D 单隐喻（如材料夹）；**不要**在提醒条、列表、上传入口再堆 3D。容器：浅底或细描边、小圆角、少嵌套；长文用字色区分即可，勿再套厚暖色卡
- 适用：补材、上传、表单、清单工具页

### T-021 · 状态头卡用材质垫层，不漂白品牌蓝
- 来源参考：用户改「理赔向导」头卡 `228:1793`（2026-07-27）
- 作用层：背景 / 材质
- 做法：蓝渐变底保留饱和；其上另叠裁切垫层（柔光团 + 丝质/纸感底材 `SOFT_LIGHT` + 极淡弧光水印 + 微颗粒）。垫层透明要低，避免洗成浅灰蓝雾卡；装饰停在头卡内，不进列表
- 适用：结果/核对状态头卡、权益摘要蓝卡
- 慎用：厚玻璃拟态；满卡强噪；再叠第二枚 3D
- 慎用：把「少用 3D」理解成删掉头图唯一锚点；提醒/原因区再套厚壳

## 支付宝系落地映射（重学后）

|------------|------------------|
| 薄荷绿 / 财富金头 | 极淡蓝雾或浅灰 + `#1677FF` 点睛 |
| 玻璃盾 / 3D 心 | **先抠透明**再叠氛围 |

## 默认配方（工具/结果页 · 重学后）

1. 顶区：T-002 淡雾溶白（勿抽干成死灰）  
2. 主视觉：T-001 + T-007 + **T-017 语义符号** + **T-019 尺度** + **T-015 浅光底座**  
3. 成功文案：T-016 蓝标题 + 轻载体（磨砂/白岛）  
4. 数字：T-018 磨砂条或同岛浅底；T-008 指标先行  
5. 内容：材料一岛即可；无意义 3D 点缀默认不加  
6. 行动色：`#1677FF` 实色点睛  
7. 验收：T-010；第一眼应是通透主物而非白框贴图
