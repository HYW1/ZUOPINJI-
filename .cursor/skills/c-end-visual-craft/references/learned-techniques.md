# 可迁移技巧库（持续追加）

本文件存放从参考图拆解中提炼、可套用到任意新 C 端需求的技巧。  
**不要**写入具体业务文案、流程步骤或单一产品专属结构。

完整拆解见：`breakdowns/215-1793-视觉参考.md`  
来源画板：Figma `215:1793`「视觉参考」花瓣分类板（缺 03/06/07）。

### T-001 · 一屏一锚点（可命名材质）
- 来源参考：section/01 主视觉锚点
- 作用层：主视觉 / 材质
- 做法：每个关键模块只放一个主角物（玻璃/金属/哑光塑料/摄影），能说出材质名；文案退到一侧或下方
- 适用：Hero、结果态、权益头图、空状态
- 慎用：多层玻璃叠罗汉；虹彩丝带铺满

### T-002 · 背景三层气雾
- 来源参考：section/02 背景与氛围
- 作用层：背景 / 光影
- 做法：实底（白/浅灰）→ 大半径模糊色团（单色相极淡）→ 少量细节（细漏光或微颗粒）；氛围主要停在页头上 1/3
- 适用：支付宝系工具页/服务页顶区
- 慎用：暗黑赛博光带；彩虹棱镜当默认皮肤

### T-003 · 左信息 · 右主物
- 来源参考：section/01
- 作用层：排版 / 主视觉
- 做法：Banner 信息成组靠左，体积物靠右；主视觉周围留呼吸，不贴标签丛
- 适用：运营位、功能介绍条
- 慎用：主物上烧字；两侧同时塞插画

### T-004 · 分层用一种手段
- 来源参考：section/04 卡片与层次
- 作用层：光影 / 卡片
- 做法：浅色界面用短软阴影；暗色界面用边缘高光；不要阴影+霓虹描边+内发光一起上
- 适用：列表卡、会员等级卡、数据卡
- 慎用：霓虹描边卡片墙（见 section/10）

### T-005 · 卡片是容器不是段落框
- 来源参考：section/04 + section/10 反面
- 作用层：层次
- 做法：能用底色分区、分割线、留白完成的层级，不要包厚卡片；卡片留给表单组、可点模块、数据岛
- 适用：首页、详情、表单
- 慎用：每段话一张卡

### T-006 · 图标两档材质
- 来源参考：section/05 插画与图标
- 作用层：图标 / 插画
- 做法：宫格功能图标统一语言（同圆角/饱和/光源）；Hero/空状态才升级玻璃或抛光材质
- 适用：入口宫格、成功/安全态主图标
- 慎用：每个小入口都重度玻璃；塑料 AI 贴纸人

### T-007 · 冷灰落地影 + 局部光
- 来源参考：section/08 排版与留白
- 作用层：光影
- 做法：主物阴影带一点冷灰/蓝灰；允许底座局部光；禁止满屏 glow
- 适用：3D 主物落地、盾/证件类隐喻
- 慎用：纯黑脏影；光带穿过正文

### T-008 · 工具页质感公式
- 来源参考：section/09 金融保险优秀案例
- 作用层：背景 / 结构 / 主视觉
- 做法：顶区极淡品牌色雾 +（可选）一枚状态主视觉 → 下方纯净表单/列表（设计系统组件）→ 模块岛用明度差而非炫光
- 适用：表单、报案/申请类工具、报告详情（映射到任意 C 端工具页）
- 慎用：把表单包进霓虹玻璃；照搬参考的绿色主题（应映射 `#1677FF`）

### T-009 · 数字舞台留白
- 来源参考：section/09
- 作用层：排版
- 做法：倒计时、金额、关键指标给予整块留白舞台；装饰退到角落或顶区
- 适用：状态页、待办倒计时、资产摘要
- 慎用：数字周围堆胶囊标签与插画

### T-010 · 反面即验收闸门
- 来源参考：section/10 反面教材
- 作用层：验收
- 做法：对照删除——霓虹描边、蓝紫墙、空洞 HUD、电商大杂烩首屏、通用 AI 柱体礼盒、高饱和软 UI
- 适用：每次改稿前后快检
- 慎用：无（本条本身是禁令）

## 支付宝系落地映射（从参考板收敛）

| 参考里常见 | 落到支付宝 C 端 |
|------------|------------------|
| 薄荷绿 / 多色主题头 | 极淡蓝雾或中性浅灰 + `#1677FF` 点睛 |
| 重玻璃拟态、彩虹丝带 | 单枚材质主物，或不用 |
| 暗黑霓虹仪表 | 默认不用；非暗黑活动页不借用 |
| 厚卡片墙 | 底色分区 + 规范列表 |
| 群像 3D 广告场景 | 工具页改为单隐喻图标；营销页才谨慎使用 |
