本文件存放从参考图拆解中提炼、可套用到任意新 C 端需求的技巧。

### T-001 · 一屏一锚点（可命名材质）
- 来源参考：section/01、05
- 作用层：主视觉 / 材质
- 做法：每屏一个主角物；能说出材质名；文案退到一侧或下方
- 适用：Hero、结果态、权益头图、空状态
- 慎用：多层玻璃叠罗汉；虹彩丝带铺满

### T-002 · 背景三层气雾
- 来源参考：section/02
- 作用层：背景 / 光影
- 做法：实底 → 大半径模糊色团 → 少量细节光/颗粒；氛围停在页头上 1/3
- 适用：支付宝系工具/服务页顶区
- 慎用：暗黑赛博光带；彩虹棱镜默认皮

### T-003 · 左信息 · 右主物
- 来源参考：section/01
- 作用层：排版 / 主视觉
- 做法：信息成组靠左，体积物靠右；主视觉周围留呼吸
- 适用：运营位、结果头图
- 慎用：主物烧字；两侧同时塞插画

### T-004 · 分层用一种手段
- 来源参考：section/04
- 作用层：光影 / 卡片
- 做法：浅色短软阴影；暗色边缘高光；勿阴影+霓虹+内发光叠满
- 适用：列表卡、会员卡、数据卡
- 慎用：霓虹描边卡片墙（section/10）

### T-005 · 卡片是容器不是段落框
- 来源参考：section/04 + 10
- 作用层：层次
- 做法：能用底色分区/分割线/留白完成的，不要包厚卡
- 适用：首页、详情、表单
- 慎用：每段话一张卡

### T-006 · 图标两档材质
- 来源参考：section/05（扩充后）
- 作用层：图标 / 插画
- 做法：宫格统一语言；Hero/空状态才升级玻璃或抛光
- 适用：入口宫格、成功/安全态
- 慎用：每个小入口重度玻璃；塑料 AI 贴纸人

### T-007 · 主物必须透明可叠（强制）
- 来源参考：section/05、09；实战反馈
- 作用层：材质 / 生图
- 做法：绿幕或干净底生成 → rembg/色键抠图 → 清边 → RGBA PNG → Figma `IMAGE+FIT`，禁止烘焙白底/云雾方板
- 适用：一切 Hero 3D（盾/心/文件夹/吉祥物）
- 慎用：未抠图直接贴；透明通道上再铺不透明底色

### T-008 · 疏朗留白 + 指标先行（纠正后）
- 来源参考：section/08 **新板**（非旧营销海报）
- 作用层：排版
- 做法：模块间大呼吸、组内紧；金额/分数/百分比极大，标签灰色退后；内边距按 8 栅格加码
- 适用：工具页、报告页、详情页
- 慎用：把旧 08 的全家福海报当留白范本；暗蓝霓虹大圆钮默认皮

### T-009 · 顶雾溶白 + 白岛长软影
- 来源参考：section/09 **扩充后**
- 作用层：背景 / 结构
- 做法：顶区极淡品牌雾溶入白；内容白岛用长距低透明软阴影浮起；列表用设计系统
- 适用：保险/服务/结果默认公式
- 慎用：照搬绿/金大面积主题墙

### T-010 · 反面即验收闸门
- 来源参考：section/10
- 作用层：验收
- 做法：对照删除霓虹描边、蓝紫墙、空洞 HUD、通用 AI 柱体礼盒、高饱和软 UI
- 适用：每次改稿前后
- 慎用：无

### T-011 · 3D 轻压卡片上沿做景深
- 来源参考：section/09
- 作用层：层次
- 做法：透明主物可轻微越过白卡上沿，制造前后景；必须已抠图
- 适用：结果头、保障头图
- 慎用：压住关键文案；未抠图的方板「假压边」

### T-012 · 摄影与 3D 勿双主锚
- 来源参考：section/09
- 作用层：主视觉
- 做法：头图以摄影或 3D 其一为主，另一退为辅或不用
- 适用：营销/保障头图
- 慎用：摄影墙 + 大 3D 同时抢第一眼

### T-013 · 极淡微纹理增触感
- 来源参考：section/08 新板
- 作用层：背景
- 做法：地形线级微纹理或细颗粒，强度以「几乎看不见但去掉会更假」为准
- 适用：高键浅色页头
- 慎用：贴图墙、强噪点、干扰正文

### T-014 · 营销群像仅限营销模块
- 来源参考：section/05（扩充后归位）
- 作用层：插画
- 做法：家庭/老人 3D 群像用于权益/情感海报；工具/表单/结果核验页改用单隐喻图标
- 适用：分流页面类型
- 慎用：工具页堆群像抢信息

## 支付宝系落地映射（重学后）

| 参考里常见 | 落到支付宝 C 端 |
|------------|------------------|
| 薄荷绿 / 财富金头 | 极淡蓝雾或浅灰 + `#1677FF` 点睛 |
| 玻璃盾 / 3D 心 | **先抠透明**再叠氛围 |
| 家庭 3D 群像 | 仅营销模块 |
| 新 08 疏朗报告/表单 | **优先模仿**的字号与留白 |
| 霓虹仪表（10） | 默认禁用 |

## 默认配方（工具/结果页 · 重学后）

1. 顶区：T-002 淡雾（可加 T-013 微纹理）  
2. 主视觉：T-001 + **T-007 透明抠图**（可选 T-011 轻压边）  
3. 文案：必须有承载底（卡/标签），禁止裸字飘氛围上  
4. 数字：T-008 指标先行  
5. 内容：T-009 白岛 + 设计系统列表；T-005 少厚卡  
6. 行动色：`#1677FF` 实色点睛  
7. 验收：T-010
