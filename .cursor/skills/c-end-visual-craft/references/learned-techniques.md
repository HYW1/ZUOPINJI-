### T-001 · 一屏一锚点（可命名材质）
- 来源参考：section/01、05
- 作用层：主视觉 / 材质
- 做法：每屏一个主角物；能说出材质名；文案退到一侧或下方
- 适用：Hero、结果态、权益头图、空状态
- 慎用：多层玻璃叠罗汉；虹彩丝带铺满

### T-002 · 背景三层气雾
- 来源参考：section/02
- 作用层：背景 / 光影
- 做法：实底 → 大半径模糊色团 → 少量细节光/颗粒；氛围停在页头上 1/3
- 适用：支付宝系工具/服务页顶区
- 慎用：暗黑赛博光带；彩虹棱镜默认皮

### T-003 · 左信息 · 右主物
- 来源参考：section/01
- 作用层：排版 / 主视觉
- 做法：信息成组靠左，体积物靠右；主视觉周围留呼吸
- 适用：运营位、结果头图
- 慎用：主物烧字；两侧同时塞插画

### T-004 · 分层用一种手段
- 来源参考：section/04
- 作用层：光影 / 卡片
- 做法：浅色短软阴影；暗色边缘高光；勿阴影+霓虹+内发光叠满
- 适用：列表卡、会员卡、数据卡
- 慎用：霓虹描边卡片墙（section/10）

### T-005 · 卡片是容器不是段落框
- 来源参考：section/04 + 10
- 作用层：层次
- 做法：能用底色分区/分割线/留白完成的，不要包厚卡
- 适用：首页、详情、表单
- 慎用：每段话一张卡

### T-006 · 图标两档材质
- 来源参考：section/05（扩充后）
- 作用层：图标 / 插画
- 做法：宫格统一语言；Hero/空状态才升级玻璃或抛光
- 适用：入口宫格、成功/安全态
- 慎用：每个小入口重度玻璃；塑料 AI 贴纸人

### T-007 · 主物必须透明可叠（强制）
- 来源参考：section/05、09；实战反馈
- 作用层：材质 / 生图
- 做法：绿幕或干净底生成 → rembg/色键抠图 → 清边 → RGBA PNG → Figma `IMAGE+FIT`，禁止烘焙白底/云雾方板
- 适用：一切 Hero 3D（盾/心/文件夹/吉祥物）
- 慎用：未抠图直接贴；透明通道上再铺不透明底色

### T-008 · 疏朗留白 + 指标先行（纠正后）
- 来源参考：section/08 **新板**（非旧营销海报）
- 作用层：排版
- 做法：模块间大呼吸、组内紧；金额/分数/百分比极大，标签灰色退后；内边距按 8 栅格加码
- 适用：工具页、报告页、详情页
- 慎用：把旧 08 的全家福海报当留白范本；暗蓝霓虹大圆钮默认皮

### T-009 · 顶雾溶白 + 白岛长软影
- 来源参考：section/09 **扩充后**
- 作用层：背景 / 结构
- 做法：顶区极淡品牌雾溶入白；内容白岛用**页底色差 + 细描边**浮起（默认不加卡片投影）；列表用设计系统
- 适用：保险/服务/结果默认公式
- 慎用：照搬绿/金大面积主题墙

### T-010 · 反面即验收闸门

### T-011 · 3D 轻压卡片上沿做景深

- 适用：结果头、保障头图
- 慎用：压住关键文案；未抠图的方板「假压边」

### T-012 · 摄影与 3D 勿双主锚
- 来源参考：section/09
- 作用层：主视觉
- 做法：头图以摄影或 3D 其一为主，另一退为辅或不用
- 适用：营销/保障头图
- 慎用：摄影墙 + 大 3D 同时抢第一眼

### T-013 · 极淡微纹理增触感
- 来源参考：section/08 新板
- 作用层：背景
- 做法：~~地形线级微纹理或细颗粒~~ → **默认不做颗粒/噪点/砂面**。触感改用光滑柔光雾、磨砂亚克力流光、干净 mesh 渐变。用户明确：**不要颗粒感及同类噪点质感**
- 适用：高键浅色页头（仅当确需且用户未禁噪点时才考虑极淡纹理）
- 慎用：**颗粒 / film grain / 砂纸噪点 / 闪点**（默认禁止）

### T-021 · 状态头卡用光滑柔光雾面，禁止线纹与颗粒
- 来源参考：用户改「理赔向导」头卡 `228:1793`（2026-07-27）
- 作用层：背景 / 材质
- 做法：贴**零噪点**蓝系柔光雾面（程序 mesh 或光滑生图）；可读白字；统计区半透明白雾即可。禁止同心圆/雷达弧/地形线；禁止颗粒/film grain/砂面/闪点
- 适用：结果/核对状态头卡
- 慎用：线纹水印；颗粒贴图；漂白雾卡

### T-022 · 材料上传用状态文案，不用孤立「+」与红绿灯标
- 来源参考：用户改「上传材料」`250:377`（2026-07-28）
- 作用层：交互入口 / 状态表达
- 做法：
  1. **已上传**：标题旁写「已上传 N 张」（品牌蓝 `#1677FF`）+ 缩略图；继续用文字链「添加」，不要再放虚线「+」方块
  2. **未上传**：标题旁写「未上传」（中性灰）+ 整区「相机图标 + 点击上传」承载底，语义完整
  3. **去掉**红「必传」等红绿灯色标；是否必传用文案/结构表达，状态只用蓝/灰，不用红绿对打
- 适用：理赔/表单材料上传列表
- 慎用：空荡「+」格子当唯一入口；红必传 + 绿已传的交通灯配色

### T-023 · 进度顶卡：未齐实心底突出，已齐弱化分区
- 来源参考：上传材料卡对比强化（2026-07-28）→ `279:380`
- 作用层：信息架构 / 状态表达 / 层次
- 做法：
  1. 先读链路，只列真实项；副标题点明「还差 N 项，其余已齐」
  2. **未齐先行 + 实心白底面板**（蓝底上最高对比）+ 大字材料名 + 实心蓝按钮「去上传」
  3. **已齐退后**：半透明浅底、更小字号/更低透明度，不再与未齐同形同权标签抢视线
  4. 禁止：三行等权清单、同尺寸「已齐/未齐」小 pill 并排、空双区、红绿灯、✓ 芯片丛
- 适用：多步工具流中间页进度卡
- 慎用：未齐与已齐视觉权重接近；与下方列表状态长期矛盾
