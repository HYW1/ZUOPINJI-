# 案例 · 定稿：玻璃盾浅环（克制）

**选用方向：** 用户指定 `161:705` G6 玻璃盾气质  
**定稿帧：** `165:689`「定稿 · 玻璃盾浅环（克制）」  
https://www.figma.com/design/DLepVQbX1Ll21Y2fh1kmyU/就医报销?node-id=165-689

## 用户约束（本轮）

- 按 G6 玻璃盾方向，**去掉金币、纸张**
- 可保留**浅底座 / 浅环**
- 容器要简单，不要复杂嵌套
- 从体验与一致性出发：不是处处都要 icon / 阴影
- 无意义元素不乱加

## 定稿结构（少容器）

1. **顶雾**：轻色洗，无摄影糊底  
2. **一个结果摘要白岛**：标题 + 说明 + 三项指标（内嵌浅底，不再套第二张卡）  
3. **一枚主视觉**：透明玻璃盾 + 浅环（无金币/纸张/文件夹点缀）  
4. **一个材料白岛**：列表与上传交互；帮助条仅功能入口，无装饰 icon  
5. **主按钮**：实色 `#1677FF`  
6. **全树无卡片 DROP_SHADOW**

## 体验原则落地

| 原则 | 做法 |
|------|------|
| 一屏一锚点 | 只保留盾，不在材料区再塞 3D 点缀 |
| 容器克制 | 摘要 1 岛 + 材料 1 岛，避免卡套卡 |
| 一致性 | 白岛统一细描边 `#D9E1EC`；功能色只用于必传/示例/主按钮 |
| 可删则删 | 无装饰环、无成功小徽章、无文件夹角标、无金币纸张 |
