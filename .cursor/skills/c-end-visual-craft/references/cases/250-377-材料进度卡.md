## 问题

旧顶卡用 ✓ / 空心圆芯片分「已收集 / 还需要」两段，看不出本步闸口是「传材料」，也难扫清哪几项已传、哪几项未传。

## 改法（换表达，不换业务）

| 元素 | 表达 |
|------|------|
| 进度 | 右上 `1 / 3 已上传` |
| 已上传行 | 材料名 +「已传 N 张」+ **实心** pill「已上传」 |
| 未上传行 | 材料名 + **描边** pill「未上传」 |
| 减负提示 | 「病情信息将从材料自动识别」 |

- 单卡；列表浅底分层，不套「已完成/接下来」厚卡
- 状态只用蓝/白实心 vs 描边，不用红绿、不用 ✓/空心圆丛
