## 场景

保险理赔审核中，用户被要求补材；从「补充材料」入口进入。

## 体验诊断（改前）

1. 补材是当前唯一关键任务，却埋在理赔服务大盘，和记录 / 安心赔抢注意力  
2. 入口按钮为线框弱样式，任务优先级与视觉权重相反  
3. 材料说明文案重复占位，不可信  
4. 状态（审核中 / 截止日期）与行动（传什么、怎么交）割裂  

## 改版策略

做**专注任务页**：状态与时限 → 清单与要求 → 上传 → 提交。  
去掉大盘噪声；主 CTA 实色 `#1677FF`（0 项时降透明，防空提交）。

## 质感

- 顶区软雾溶白  
- 摘要 / 清单各一白岛 + 细描边，**无卡阴影**  
- 不堆 3D 图标；帮助仅文字入口  
- 截止日用暖色标签点睛，必传用红标签  

## 可迁移点

- 任务型入口应落到「单任务页」，不要回大盘  
- 状态 + 时限放首屏摘要，清单只承载可执行项  
- 空态主按钮可降强调，进度文案同步反馈
