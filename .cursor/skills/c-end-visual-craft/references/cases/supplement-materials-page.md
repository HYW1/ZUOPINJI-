## 硬约束

- 只优化质感与层次，**不增删**原图/现稿模块与文案
- 禁止借题发挥改成「理赔大盘」或另一套任务页信息架构

## 内容清单（须全部保留）

1. 导航标题「补充材料」  
2. 「请补传以下材料：」+ 拍摄清晰完整提示  
3. 快赔提示（补齐后重新启动 3 日快赔计时）  
4. 「检查报告」：必须提供 · 材料示例 · 说明 · 补传原因（含 `[送检报告 血压检测]`）· 上传检查报告  
5. 「宠物治疗中照片」：必须提供 · 材料示例 · 说明 · 补传原因 · 已传照片  
6. 底栏：暂存 · 提交申请 · 取消理赔  

## 诊断 → 改法

| 问题 | 改法 |
|------|------|
| 顶区扁平 | 极淡蓝雾溶入页灰（T-009） |
| 快赔条图标弱（emoji） | 橙色时钟徽章 + 关键句橙强调 |
| 上传入口像普通链接 | 浅蓝虚线承载行（仍是同一行动） |
| 补传原因长文难读 | 浅暖底 + 细描边承载（文案不动） |
| 卡片发飘 | 白岛 + `#E8EEF5` 细描边，**无投影** |
| 底栏弱 | 白底栏 + 主按钮实色 `#1677FF` |

## 可迁移点

- 补材工具页：一屏一紧迫锚点（时限/快赔），不要堆营销主视觉  
- 长「原因」文案用浅色承载底，比裸彩色字更稳  
- 上传类行动用浅底虚线行提升可点性，无需新模块
