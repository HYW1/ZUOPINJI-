## 问题拆解（改前）

1. **无主锚点**：首屏只有标题+灰提示，看不出「紧急补材任务」  
2. **信息等权**：说明 / 原因 / 上传字重接近，任务路径被长文淹没  
3. **快赔条弱**：浅橙细条，时效利益点不够跳  
4. **上传不像行动**：蓝色文字行，可点面积过小  
5. **材料卡像文档粘贴**：缺任务序号与操作面层级  
6. **旧「微调改后」失败**：只改描边/小底色，并排对比几乎无差 → 作废  

## 视觉方案（改后必须一眼可见）

| 模块 | 做法 | 对应技巧 |
|------|------|----------|
| 任务头图 | 淡蓝雾 + 左标题组 + 右「材料夹」单隐喻 | T-001 / T-009 / T-014 |
| 快赔提示 | 白卡 + 大橙时钟徽章 + 关键句加粗橙 | 层次 / 色彩克制 |
| 材料任务卡 | `01`/`02` 序号徽章 + 必须提供 + 原因浅暖承载 | T-005 |
| 上传 | 大虚线操作面 + 圆形「+」 | 行动可感知 |
| 照片 | 加大缩略图作完成态锚点 | 主视觉退为证据 |
| 底栏 | 白岛 + 暂存描边 / 提交 `#1677FF` | 收束 |

**禁止：** 卡投影、蓝紫大渐变、玻璃堆、删改原文案模块。
