## 原图内容清单（必须全部保留）

1. 导航：返回 · 标题「补充材料」· 客服 · 记录  
2. 主标题「请补传以下材料：」+ 拍摄清晰完整提示

## 质感改动（相对原图）

- 页底浅灰 + 白卡细描边分层，**无卡阴影**  
- 快赔条：浅暖底 + 细描边；关键句橙强调  
- 「补传原因」：浅暖承载底，橙字保留，提升可读（不改文案）  
- 主行动 `#1677FF`；照片裁自原图像素，不换题材
