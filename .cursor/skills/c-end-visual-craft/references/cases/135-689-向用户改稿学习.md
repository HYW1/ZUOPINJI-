## 我之前为什么丑（反面教材）

| 问题 | 我的错误 | 用户改法 |
|------|----------|----------|
| 主物语义 | 通用「勾选盾」，像安全 App 贴纸 | **医疗十字盾**，玻璃通透，浅环/浅光底座 |
| 主物尺度 | 小、贴在白卡角落，像角标 | 足够大，融入顶区；或轻压白卡上沿 |
| 成功文案色 | 墨黑标题，成功态无品牌感 | **品牌蓝大标题**（约 40）+ 灰说明 |
| 氛围 | 抽干成冷灰底，或假雾矩形 | 软蓝顶雾/氛围溶白，主物有落点 |
| 浅底座 | 强行烤进 3D 图，或没有 | **图下叠模糊浅蓝椭圆**（右稿）/ 资产自带浅环（左稿） |
| 容器 | 实心白卡+描边到处套，死板 | 左：文案轻载体 + **磨砂数字条**；右：摘要一岛，指标内嵌浅底 |
| 装饰 | 金币纸张/多余角标乱加 | 只保留主物；无金币、无纸张点缀 |
| 克制误解 | 为「简单」把质感抽空 | 克制的是杂物，不是材质与光 |

## 正向公式（可迁移）

1. **顶区**：软蓝氛围溶白 → 左信息（蓝标题）→ 右主物（医疗玻璃十字盾）
2. **浅底座**：主物下方 1～2 个低透明模糊椭圆，或资产内极浅环；禁止金币/票据堆砌
3. **指标**：要么磨砂条浮在氛围上（轻），要么收进同一摘要岛的浅底分区（稳）
4. **材料区**：系统列表白岛即可；不要再塞 3D 小文件夹「点缀」
5. **验收**：第一眼是「通透医疗主物 + 蓝成功态」，不是「白框贴丑图」
