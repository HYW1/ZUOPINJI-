# Case · 上传材料页进度说明卡

- **File**: `DLepVQbX1Ll21Y2fh1kmyU`（就医报销260728）
- **Node**: `226:1755` 上传材料
- **Backup**: `250:377` 上传材料-改前
- **Date**: 2026-07-28

## 场景

用户已选就医票据 → 已选保单与部分就医信息 → 到达传材料。实际可能只需核对少量材料。

## 体验问题（改前）

顶卡文案「正在收集以下信息」+ 8 个空态字段芯片，像还要填一堆表单，和当前阶段（传材料）冲突，流程读不懂。

## 改法

1. **进度顶卡**（`250:512`）：第 3/3 步 + 「还差材料即可申请」
2. **步骤条**：✓选票据 → ✓选保单 → `3 传材料`（当前白底蓝字）
3. **已完成 / 接下来**：摘要已选内容；明确「核对并补齐、可能已很少」；提示就医信息已带入
4. **白岛文案**：标题改为「上传理赔材料」；副文案说明必传 3 项与已识别；每类下「已自动识别请核对」
5. **主按钮**：材料已齐，申请理赔

## 注意

`figma.createAutoLayout` 默认白底，蓝底上的白字会被盖成白条——容器 `fills` 需显式 `[]`。

## 验收

- 一眼能分清已完成 vs 当前要做
- 降低「还要传很多」的预期负担
- 仅改上传材料页，其它页未动
