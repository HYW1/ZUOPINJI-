# 反 AI 模板快速检查

改稿前后各扫一遍。任一项为「是」→ 必须改。

## 首屏 / Hero

- [ ] 是否只有大标题 + 空洞装饰、没有可识别主视觉物？
- [ ] 是否用大面积蓝紫 / 粉紫渐变当背景？
- [ ] 是否堆了徽章、胶囊、统计条、促销贴抢第一眼？

## 结构

- [ ] 是否每一段文案都包在厚阴影卡片里？
- [ ] 是否多层玻璃拟态叠在一起？
- [ ] 是否用无意义 glow / 外发光制造「高级感」？

## 素材

- [ ] 插画是否像通用 AI 贴纸（塑料人、漂浮 3D 图标、空洞几何）？
- [ ] 是否一次生成整页 UI 糊图当背景？
- [ ] 文字是否烧进图里导致无法替换？
- [ ] 是否用同心圆 / 雷达弧 / 地形细线 / 装饰线纹当卡片或页头背景？（**永久禁止**，C/B 端都不要）
- [ ] 是否叠加颗粒感 / film grain / 砂面噪点 / 闪点当「质感」？（**默认禁止**，改用光滑柔光雾）

## 色彩与品牌

- [ ] 品牌蓝 `#1677FF` 是否被滥用成大色块墙？
- [ ] 是否出现无品牌依据的装饰紫渐变？
- [ ] 点缀色是否超过 1 个且互相抢戏？

## 与规范的关系

- [ ] 是否为了「好看」破坏了设计系统组件尺度？
- [ ] 质感是否靠特效堆砌，而不是层次 / 材质 / 主视觉？

全部为「否」才进入终验收。
