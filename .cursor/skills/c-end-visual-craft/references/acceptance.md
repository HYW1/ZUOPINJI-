# 终验收表

用于整页完成后的勾选。模块过程截图另存，不替代本表。

## 观感

- [ ] 第一眼不像「AI 拼出来的后台模板」
- [ ] 有明确主视觉锚点
- [ ] 装饰没有抢走标题 / 关键信息 / 主 CTA

## 规范与质感来源

- [ ] 设计系统组件尺度仍正确（字号、间距、圆角、按钮）
- [ ] 行动色仍以 `#1677FF` 为点睛，无廉价大面积蓝紫渐变
- [ ] 质感来自层次 / 材质 / 主视觉，而非 glow / 玻璃堆叠 / 假特效

## 素材与可维护性

- [ ] 生图按单模块完成并逐张校验后嵌入
- [ ] 生图风格与页面统一
- [ ] 素材可替换、可复用（无烧字、无一次性整页糊图）

## 过程证据

- [ ] 每个改动模块有过程截图
- [ ] 有整页前后对比截图

## 可迁移性

- [ ] 本次学到的技巧已用「可迁移」语言记下（不绑死单一业务文案/流程）
