# 生图 Playbook（单张循环）

禁止：一次生成整页 UI 糊图。  
允许：单模块主视觉 / 单材质 / 单插画 / 必要时单组图标。

## 循环

```text
定义模块需求 → 写提示词 → 生成一张 → 校验 → 通过则入库
                                      └ 不通过则改提示词重生成（同模块）
→ 放入 Figma 对应模块 → 截图验收该模块 → 下一模块
```

## 提示词必填项

1. **类型**：主视觉 / 材质纹理 / 场景插画 / 产品物  
2. **平台气质**：支付宝系 C 端；干净、可信、生活感  
3. **画幅与安全区**：适配 750 宽模块；主体不贴边  
4. **主物体**：具体、可识别  
5. **光**：方向 + 软硬 + 色温  
6. **材质**：可命名（纸 / 布 / 雾 / 金属细边 / 磨砂…）  
7. **色彩**：中性为主；点缀接近 `#1677FF`；禁大面积紫渐变  
8. **禁止项**：玻璃拟态、通用 AI 贴纸、塑料 3D 人、无意义 glow、烧字、整页假 UI  

## 透明底与抠图（强制）

主视觉 / 图标类素材 **禁止** 带着烘焙背景（白底、氛围底、棋盘格）直接贴进页面。

推荐流程（二选一或组合）：

1. **绿幕生成**：提示词要求纯色绿幕 `#00FF00`，无棋盘格、无白卡底座  
2. **抠图处理**：用 `rembg` 或色键去底 → 清理毛边 → trim → 导出 RGBA PNG  
3. **Figma 放置**：矩形节点只用 `IMAGE` + `FIT`，**不要**叠不透明底色；阴影用图层 effect，不要画进图里  

校验：四角 alpha 必须为 0；把图叠在灰色/氛围底上预览，不应出现方板。

## 校验清单（每张图）

- [ ] 不像通用 AI 贴纸  
- [ ] 光向 / 色温可与页内其他元素统一  
- [ ] **已抠成透明底 RGBA**（或确认四角 alpha=0）  
- [ ] 未烧录文案 / 未画假按钮 / 无棋盘格 / 无白方板  
- [ ] 可在其他类似模块复用（不过度绑定本次业务文案）  
- [ ] 尺寸与目标模块比例匹配，无需极端拉伸  
- [ ] 若页面有新文案块，必须有承载底（卡片/标签底），禁止裸字飘在氛围上

## 入库命名建议

```text
mv-<page>-<module>-<role>-v<n>.png
例：mv-home-hero-product-v2.png
    tx-home-header-paper-v1.png
    il-result-success-scene-v1.png
```

`mv` 主视觉 · `tx` 纹理材质 · `il` 插画 · `ic` 图标
