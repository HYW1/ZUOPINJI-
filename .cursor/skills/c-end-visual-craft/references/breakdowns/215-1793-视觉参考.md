## section/01 主视觉锚点（217:1800）

### 1. 主视觉锚点是什么
- 第一眼落点：右侧/居中的 **可触摸 3D 物**（磨砂玻璃卡片、半透明方块、水晶图标、金属环、丝带体、立体数字）
- 锚点类型：材质化 3D 物 / 抽象几何物
- 服务目标：让 Banner/模块「有主角」，文案退到一侧，避免空洞 Hero

### 2. 背景如何做氛围
- 手法：浅色平涂 + 极轻蓝雾；少数深色用远景网格/地平线
- 强度：背景弱、主体强；渐变多为单色相轻过渡
- 边界：主体与背景靠软阴影/景深分离，少用硬描边框住主视觉

### 3. 层次怎么分
| 层 | 内容 | 手法 |
|----|------|------|
| 前景 | 3D 主物、高光边缘 | 高光、折射、接触阴影 |
| 内容 | 标题/副文案 | 左文右图或上图下文，字重对比清晰 |
| 背景 | 浅底或轻雾 | 不与主体抢饱和度 |

### 4. 材质与光影技巧（可复用）
1. **一物一材质**：玻璃/金属/哑光塑料说得清，高光有方向  
2. **左右分栏锚点**：信息区稳，主视觉区给体积物  
3. **轻体积阴影**：短而软的接触影，不用大圈 glow 撑高级感  

### 5. 排版与留白节奏
- 文案块紧凑成组；主视觉周围留呼吸  
- 标题明显大于辅助说明；不在主视觉上贴满标签

### 6. 可迁移到我的稿
- 每个关键模块只保留 **一个** 材质化主视觉物  
- Banner 可用「左信息 + 右主物」  
- 用可命名材质替代扁平贴纸图标当 Hero  

### 7. 不要学
- 大面积蓝紫霓虹花/涡旋当默认气质（偏运营炫技）  
- 多层玻璃拟态叠罗汉  
- 虹彩丝带无节制铺满（支付宝日常页过营销）

## section/02 背景与氛围（217:1804）

### 1. 主视觉锚点是什么
- 本板主角是 **氛围本身**：柔光色雾、棱镜漏光、丝带光带  
- 适合做页头/分区底，而不是替代内容

### 2. 背景如何做氛围
- 手法：高键浅底 + 大半径色雾；少量棱镜细光；偶见暗底光带  
- 强度：浅色系极轻；暗色系才提高对比  
- 边界：色雾溶入白/浅灰，无硬色块切割

### 3. 层次怎么分
| 层 | 内容 | 手法 |
|----|------|------|
| 前景 | （本板较少）细光斑/漏光 | 透明度低、面积小 |
| 内容 | 留给真实 UI | 保证对比度 |
| 背景 | 底色 + 大气色团 | 100px+ 级模糊感 |

### 4. 材质与光影技巧（可复用）
1. **三层背景**：实底 → 大面积模糊色团 → 少量细节光/颗粒  
2. **漏光代替贴图**：细长高光条模拟晶体反射，比乱贴纹理更干净  
3. **1–2 色相 + 中性**：蓝或暖橙之一为主，溶进白/深黑  

### 5. 排版与留白节奏
- 氛围集中在页头或模块顶带；内容区尽快回到稳白底  
- 不让光带穿过正文影响阅读

### 6. 可迁移到我的稿
- 支付宝页头：极淡蓝雾/微纹理，而不是大面积品牌蓝墙  
- 分区用「浅底色差 + 留白」，少用厚卡片分隔  

### 7. 不要学
- 暗黑赛博紫青光带当默认 C 端皮肤  
- 彩虹棱镜铺满首屏  
- 用强 glow 代替信息层级

## section/04 卡片与层次（217:1808）

### 1. 主视觉锚点是什么
- 好例子里：大数字、等级图标、单枚插画、状态色条  
- 差趋势（板内也有）：每块都发光、每块都是厚卡片

### 2. 背景如何做氛围
- 正例：浅灰/浅蓝顶雾 + 白内容区  
- 暗色会员卡：深蓝底 + 卡片内轻渐变，外圈不炸光

### 3. 层次怎么分
| 层 | 内容 | 手法 |
|----|------|------|
| 前景 | 关键数/CTA/等级标 | 字号与饱和度抬高 |
| 内容 | 列表、宫格、说明 | 分组、分割线、内边距 |
| 背景 | 页底色 | 与卡片明度差很小即可分层 |

### 4. 材质与光影技巧（可复用）
1. **浅色用软阴影，暗色用边缘高光** — 二选一，别两套叠满  
2. **卡片是交互容器，不是段落外框** — 能用底色分区就不用卡  
3. **一张卡一个锚点**（数/图标/小插画），避免卡内再堆卡  

### 5. 排版与留白节奏
- 组内紧、组间松；宫格对齐  
- 数据卡：主数字极大，标签灰色退后

### 6. 可迁移到我的稿
- 首页：顶区轻氛围 + 中部规范组件 + 底区列表  
- 会员/等级：色相区分等级，阴影极轻  
- 用字重层级代替「再包一层卡片」

### 7. 不要学
- 霓虹描边卡片墙  
- 运营大促卡的高饱和黄红轰炸（除非真是大促页）  
- 深色玻璃+内发光当支付宝默认列表皮肤

## section/05 插画与图标（217:1812）

### 1. 主视觉锚点是什么
- 大图标：嫩芽+上升、水晶盾牌  
- 成套功能图标：统一饱和度的软 3D / 轻体积双色

### 2. 背景如何做氛围
- 主图标可带淡几何光晕/六边形淡线，但透明度极低  
- 图标集本身自带底色块时，页面底保持干净

### 3. 层次怎么分
| 层 | 内容 | 手法 |
|----|------|------|
| 前景 | 主图标高光、核心符号 | 锐利高光点 |
| 内容 | 可识别图形语义 | 隐喻清晰（盾=安全，芽=成长） |
| 背景 | 淡圆环/网格 | 不抢识别

### 4. 材质与光影技巧（可复用）
1. **功能图标一套语言**：同圆角、同饱和、同光源  
2. **Hero 图标可升级材质**（玻璃/抛光），列表图标保持更克制  
3. **体积靠柔和两阶色+一点高光**，不要塑料贴纸风  

### 5. 排版与留白节奏
- 主图标周围留足负空间  
- 图标网格间距均匀，避免忽大忽小

### 6. 可迁移到我的稿
- 结果页/空状态：一枚高质量主图标 + 一句说明  
- 宫格入口：统一软 3D 或统一线性，禁止混搭三套风格  

### 7. 不要学
- 通用 AI 塑料人/漂浮无意义几何  
- 每个小入口都上重度玻璃拟态（成本高且吵）  
- 图标上烧字

## section/08 排版与留白（217:1816）

### 1. 主视觉锚点是什么
- 盾牌/银行建筑/家庭场景等 **单一大隐喻**  
- 落地页：中心主物 + 大数字/利益点 + 底部主 CTA

### 2. 背景如何做氛围
- 白底或极淡蓝/粉雾  
- 摄影类用柔和色罩在照片周围，而不是硬拼贴

### 3. 层次怎么分
| 层 | 内容 | 手法 |
|----|------|------|
| 前景 | 3D 主物、主 CTA | 体积感 + 实色按钮 |
| 内容 | 标题、利益点、说明 | 严格字号阶梯 |
| 背景 | 浅氛围 | 不穿插正文

### 4. 材质与光影技巧（可复用）
1. **顶光/边缘光** 让主物从扁平底上浮起  
2. **阴影带一点冷灰/蓝灰**，避免纯黑脏影  
3. **局部光**（底座一圈）可以，满屏 glow 不可以  

### 5. 排版与留白节奏
- 上主视觉 → 中信息 → 下行动，纵向节奏清晰  
- 大数字与说明之间有明显空隙  
- 模块内边距充足，显得「贵」而不是挤

### 6. 可迁移到我的稿
- 营销/权益页：一锚点 + 一利益句 + 一主按钮  
- 保险/保障类可用「盾」等隐喻，但材质要克制、品牌蓝点睛  

### 7. 不要学
- 全家福 3D 群像过满（信息页易显广告）  
- 粉红大按钮与多色盾牌同时打架  
- 把摄影心形框当所有页的默认 Hero

## section/09 金融保险优秀案例（217:1820）

### 1. 主视觉锚点是什么
- 正例：顶区一枚 **状态主视觉**（玻璃盾+勾、文件夹+放大镜）  
- 或摄影人像作为内容锚（偏内容社区，慎用于工具页）

### 2. 背景如何做氛围
- 顶区：薄荷/浅蓝 **极淡** 纵向过渡到白  
- 内容区：白卡片「岛」落在浅灰/浅色底上  
- 不用大面积饱和渐变墙

### 3. 层次怎么分
| 层 | 内容 | 手法 |
|----|------|------|
| 前景 | 状态图标、主 CTA、关键时间/数字 | 放大、实色 |
| 内容 | 表单字段、步骤、图表、时间轴 | 规范列表/分割 |
| 背景 | 顶氛围 + 浅底 | 氛围不超过首屏上 1/3|

### 4. 材质与光影技巧（可复用）
1. **顶区轻材质图标 + 下方纯净表单** — 质感集中在锚点  
2. **卡片靠明度差与软阴影**，描边极淡或不用  
3. **图表细描边、低饱和点缀**，状态色克制  

### 5. 排版与留白节奏
- 步骤条/时间轴提供秩序  
- Label / Value 对齐；主数字/倒计时给予整块留白舞台  
- 表单工具页可以几乎无插画，靠秩序感建立质感

### 6. 可迁移到我的稿（最贴近支付宝 C 端）
- 工具/表单页：规范组件 + 顶区轻氛围 + 可选一枚状态主视觉  
- 报告/详情：模块岛 + 细分割 + 一枚主题 3D  
- 进度/倒计时：数字做舞台，装饰退到角落  

### 7. 不要学
- 照搬绿主题（应映射回支付宝蓝 `#1677FF`）  
- 体育/游戏暗黑大图风套到金融工具页  
- 为「好看」把表单改成炫光卡片

## section/10 反面教材（217:1824）

> 本板是 **不要学** 清单的视觉证据，技巧以反例形式固化。

### 反面模式（出现即改）
1. **霓虹描边卡片墙**（青/品红描边每个模块）  
2. **蓝紫玻璃拟态 + 内发光** 冒充高级感  
3. **一切内容包厚卡片**，无留白节奏  
4. **空洞 HUD 组件**（发光圈、空仪表）无信息  
5. **电商大杂烩首屏**（多色 Banner + 图标丛 + 无主锚点）  
6. **通用 AI 3D 柱体/礼盒** 配粉彩模板页  
7. **高饱和软 UI / 新拟态** 阴影脏且吵  
8. **深浅对比断层**：一张荧光总览卡 + 其余死黑扁平  

### 可迁移的「反向原则」
- 看到 glow，先问：删掉后信息是否更清楚？是则删  
- 看到每段一卡，先问：能否改成底色分区/分割线？  
- 看到蓝紫渐变墙，先问：能否变成中性底 + `#1677FF` 点睛？
